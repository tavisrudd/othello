# The Point-Class Rank Functional under Birational Wall Crossing

This repository contains the manuscript source, bibliography, and release
checks for *The Point-Class Rank Functional under Birational Wall Crossing:
Exact One-Wall Identities toward the \(X\times\mathbf P^2\) Problem*.

The paper proves an exact common-open point-column identity for smooth
projective simple VGIT walls and a path-local point-row theorem for projective
ordinary flops. It also gives analytic and Fourier--Laplace countermodels
which isolate the remaining two-wall obstruction. The factorization statement
is conditional on an explicitly named directed target-support hypothesis.
For a smooth cubic threefold X, this is the remaining assembly problem in the
point-row approach to X × P²; the paper does not claim that product is
irrational.

Run make check to build and verify the paper.
