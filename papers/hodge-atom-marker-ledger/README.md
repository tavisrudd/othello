# Hodge atoms as occurrence-indexed marker ledgers

[![DOI](https://img.shields.io/badge/DOI-10.5281%2Fzenodo.22036391-blue.svg)](https://doi.org/10.5281/zenodo.22036391)

[Download the paper (PDF)](hodge_atom_marker_ledger.pdf)

This short companion note identifies the standard Hodge-atom construction
with an occurrence-indexed marker ledger. It separates the abstract atom
quotient from its geometric realizations and derives the strictly one-step
rank-two projective-bundle obstruction.

The note does not state or investigate a two-step or all-stabilization
theorem.

Build and check with:

```sh
make check
```
