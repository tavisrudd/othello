# Non-formal / blog-style outputs

A collection for informal deliverables — engineering-report write-ups, blog-style HTML, and
interactive demos — as opposed to the formal math manuscripts in `papers/` and the sequence
packages in `oeis-submissions/`. Different audience and venue (project page / blog / technical
report), so they are grouped apart rather than judged against paper-review standards.

Each subdirectory is one output cluster.

- `queens-n18/` — the n=18 Non-Attacking Queens solve: an engineering-style write-up plus a
  blog-style HTML report and an interactive "explorable" demo.

Room for future blog/demo posts here.
