# Level-Two Stable Rationality for Quartic del Pezzo Surfaces

This manuscript proves that a smooth quartic del Pezzo surface over a
characteristic-zero field, with a rational point and stably permutation
geometric Picard lattice, becomes rational after two affine variables.  It
applies the result to both Tschinkel--Zhang cubic families and combines it
with the one-stabilization irrationality theorem to obtain exact threshold
two and explicit four-dimensional cancellation counterexamples.

Build and verify from this directory with:

```sh
make check
```

The exact tangent-incidence certificate is checked with SymPy 1.14.0.  The
mathematical proof, descent argument, and trusted boundary are in the paper's
verification section.  This directory is a new manuscript; it does not
replace or modify the earlier all-stabilizations manuscript on disk.
