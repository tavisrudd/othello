# Companion-source status

This directory preserves the R8--R10 companion record; its statements are not
claims of the current submission.

The degree-one-gcd branches retained in these archival sources are vacuous for
rank-two Hankel witness systems.  Lemma
`lem:basepointfree-off-persistent` in the main manuscript proves that every
nonconstant geometric gcd lies in the persistent second-catalecticant carrier:
rank-one Hankel systems have gcd degree one, while rank-two common-factor
systems have gcd degree two.  Consequently, the gcd-one incidence and minor
terms in these files are redundant over-exclusions already contained in the
relevant pullback of that carrier.  Their conditional ambient-linear-system
calculations are retained only to document the earlier fixed-level analysis;
they are not a separate Hankel stratum and are not used by the arbitrary-
redundancy theorem.

Before this companion record is released or cited as an autonomous proof, the
empty branches should be removed and its deletion budgets sharpened.
