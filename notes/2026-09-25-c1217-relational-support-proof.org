* DONE A: State the finite theorem and its boundary

Authority: [[file-rev:8d0911cc1:~/src/othello/notes/2026-09-22-c1217-relational-support-proof.md][C1217 card]]. The Boolean argument in the [[file-rev:8d0911cc1:~/src/othello/notes/2026-09-22-c1211-min-plus-design.org][design memo]] is: supported rows lie in the least model; a closed set contains it. This task formalizes that Boolean implication and the separate complement-domain lemma. It does not formalize weighted min-plus optimization or claim that Rust is mechanically verified.

The mathematical program is a finite ground-atom universe (=Fintype Atom=), a finite set of input facts, and a finite set of *admitted ground rule instances* (=Finset GroundRule=). Each rule has one head and a finite conjunctive body. The rule-admission premise at this abstraction level is membership in that exact admitted set; a witness cannot cite an arbitrary rule. The source parser, range restriction, variable unification, finite grounding, and proof that the admitted set equals every source rule match are outside the theorem. The theorem is stronger than Rust's body-length policy: it accepts any finite body list, while Rust admits at most four atoms. A [[file-rev:8d0911cc1:~/src/othello/lean/WeightedRules/RelationalSupport.lean][specialization to =GroundAtom signature domain=]] makes the relation signature, finite value domain, and every ground tuple coordinate explicit, including nullary relations.

For a claimed set =S=, =Closed P S= requires every admitted input fact and every head of a rule whose body lies in =S=. =RankedSupport P S rank= requires each claimed atom to be an input fact or the head of an admitted rule whose body atoms lie in =S= at strictly smaller natural-number ranks. Facts are roots; strict descent excludes a self-supporting cycle. The conjunction is deliberate: closure prevents omissions, while support prevents invented tuples. The theorem identifies =S= with the inductively generated =Derivable P= set, proves =step P S = S=, and proves =S= is contained in every closed set. This is least fixedness for the admitted finite ground program, not a statement about source text by itself.

* DONE B: Prove support, closure, and independent controls

The [[file-rev:8d0911cc1:~/src/othello/lean/WeightedRules/RelationalSupport.lean][formal module]] proves =rankedSupport_subset_closed= by strong induction on the claimed rank. It applies that result to the inductively derivable set for =rankedSupport_derivable=. The converse, =derivable_subset_closed=, is induction on a finite derivation. =closed_rankedSupport_iff_derivable= combines both inclusions; =closed_rankedSupport_leastFixed= adds fixedness of the immediate-consequence operator. =groundAtoms_leastFixed= instantiates the result at the existing relational coordinate type. No proof step assumes a checker verdict or a producer's success bit.

The [[file-rev:daf9ba1f9:~/src/othello/lean/WeightedRules/RelationalSupportChecks.lean][finite controls]] discharge both hypotheses for a two-atom chain. A partial claim has ranked support but omits the rule consequence, so closure fails. A self-cycle without an input fact is closed but has no strict ranked support. The latter two are distinct negative controls: deleting either main hypothesis would admit one of them. The checks also synthesize finite enumeration and decidable equality for an actual unary =GroundAtom= signature, so the relational specialization is instantiable rather than only polymorphic notation.

* DONE C: Formalize the complement-domain statement

For a negated relation, the checker materializes =D_1 × ... × D_k − R=. The formal [[file-rev:8d0911cc1:~/src/othello/lean/WeightedRules/RelationalSupport.lean][=restrictedComplement_exact=]] says membership in this restricted complement equals absence from the source relation on every positive-body assignment under three explicit hypotheses: =rangeRestricted= puts each queried value in a corresponding positive binding column; =layerComplete= includes those binding values in its chosen domain; and =relationExact= identifies the materialized negative relation with the checked source relation at the frozen layer boundary. =empty_column_excludes_positive= proves that an empty chosen column excludes every such assignment. A same-layer derived *binding* relation may not have its final column yet, so the implementation uses the full dictionary as that column's chosen domain. The source-side [[file-rev:8045e30:~/src/ergodis-private/docs/adr/0004-rel-lowering-ir.md][construction argument]] and [[file-rev:8d0911cc1:~/src/othello/notes/2026-09-24-c1205-transferable-rel-evidence.org][C1205 evidence]] explain and check that policy; the Lean lemma does not verify the compiler's computation of these sets.

The theorem concerns a positive-body binding followed by a negated lookup against a frozen, exact relation. It does not lift the positive fixed-point theorem across arbitrary stratified negation, same-layer negation, aggregation, or weighted recursion. Each layer needs its own admitted ground program and verified input relation from the preceding layer before the Boolean theorem applies.
