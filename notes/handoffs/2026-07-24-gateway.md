## The gateway object and its avatars

A **gateway object** (the project's own term) is a small exceptional configuration with several
reversible presentations that transport theorems among finite geometry, codes, groups, algebraic
geometry, association schemes, and quantum information, because each presentation keeps a small
forgotten decoration (a matching, sign, sheet, flag, or orientation) that makes an otherwise
many-to-one transform invertible. The Clebsch six-arc is the prototype. Its avatars, with the fact
this lane turns on — the **field-dependence of each avatar's rigidity**:

| Avatar            | Presentation                                                        | Rigidity statement                                                                                              | Field-dependence                                                                 |
|-------------------|---------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------|
| Deep-hole locus   | uncovered locus `U(A)` of the arc = deep-hole syndrome directions   | `U(A)` on a conic ⟺ Clebsch ⟺ `Stab ⊇ A_5` (`clebsch`); `U(A)` reconstructs the parent arc (`arcs`); higher-redundancy deep-hole classification (`beyond4`) | **Sporadic** — conic-filling only `q=11` at `k=6`; factorizations `(q−6)(q−9)`, `(q−4)(q−11)` |
| Modular carrier   | cross-incidence code pair → perfect code → endotrivial Lagrangian carrier | seven-gate recognition `cross-design → perfect code → endotrivial core → unique nonsplit carrier` (Modular Gateway Theorem, C474) | **Sporadic** — proved `q=7` (binary Hamming / `F_2`), `q=11` (ternary Golay / `F_3`); `q=23` boundary |
| Quantum AME / LU  | equal-phase CSS / `AME(6,d)` stabilizer state of the `[6,3,4]_q` code | local-unitary equivalence = local-Clifford equivalence (`ame-lu`, C560/C561); `H_3` separation from GRS         | **Uniform** — holds over *every* prime power                                     |

The object is exceptional in every avatar, yet its rigidity is field-sporadic in the incidence and
module avatars and field-uniform in the quantum avatar. That contrast is the lane's subject.

### Distilled facts each card needs (no re-read required)

- **The shared dictionary (one theorem, three renderings).** Six-arc = codimension-three MDS
  parity system; an uncovered point = a distance-three deep-hole syndrome direction; a secant index
  = a weight-two coset-leader count. One Lean library (`RelativeConicArcs`) serves all three
  geometric papers. Sources: `arcs` Prop. "syndrome form of relative completeness"; `clebsch`
  introduction; `beyond4` "syndrome–Hankel dictionary".
- **Deep-hole sporadicity mechanism.** `clebsch` chord-defect `|U(A)| = q²−14q+55 − c(A)` with
  `0 ≤ c ≤ 15` forces `c = (q−6)(q−9)`, hence `q ∈ {4,5,9,11}` before geometric exclusions
  (Sylvester-graph clique number five kills `q=9`); the family off-conic excess `(q−4)(q−11)` for
  `q ≡ 3 (mod 4)` isolates `q=11`. `beyond4`: at redundancy five the deep holes split into
  *persistent* families (tangent; conjugate-secant, parameterized by the norm-one torus
  `T/T^{r−1}` mod inversion and Frobenius) plus **sporadic** `PGL_2(q)`-orbits occurring exactly at
  `q ∈ {7,8,9,11,13,17,19}`.
- **Modular gateway (C474).** Two proved rows, `q=7` / `F_2` and `q=11` / `F_3`; the `q=23` binary
  Golay row is a boundary where the endotrivial carrier still exists but `PSL_2(23)` has no
  index-23 subgroup, so the degree-`q` geometric sheet cannot be realized. The theorem is a
  deliberate two-case-plus-boundary statement, not an all-field one.
- **Quantum uniformity (`ame-lu`).** LU = LC for equal-phase CSS states of every linear `[6,3,4]_q`
  MDS code over every prime power (C560); the argument is MDS-shortening to a `q²` stabilizer whose
  diagonal Weyl-axis tensor forces every local action to be Clifford — manifestly field-independent.
- **Cold-read negative that shaped the lane (2026-07-24).** The tempting "`A_5` = the redundancy-3
  instance of `beyond4`'s persistent torus family" does **not** typecheck: Clebsch is a length-six
  *short* non-GRS code, whereas the torus family lives on the *full* length-`(q+1)` normal rational
  curve and is empty at `r=3` (`dim W_f = r−3 = 0`; a common quadratic factor needs `r ≥ 4`).
  Clebsch's true cousin is `beyond4`'s **sporadic** orbits, not its persistent family. This is why
  the lane's spine is sporadic-vs-uniform, not a torus specialization.

## Central question and framing

**When an algebraic invariant of the gateway object is transported across presentations, which
transported invariants are field-sporadic — pinned to exceptional `q` by an arithmetic
factorization — and which are field-uniform, and what mechanism decides?**

Supporting sub-questions, distilled from the cross-paper incidence agenda:

1. Is there a single defect identity of the shape *ambient capacity − legal locus = visible
   collisions + invisible obstructions* common to the deep-hole, modular-carrier, and
   entanglement avatars?
2. When does containment of the transported locus in a low-degree / low-rank object force a large
   automorphism group? The `clebsch` degree-≤3 rigidity is the first exact instance.
3. Which computer censuses admit an invariant-theoretic replacement? The `A_5` orbit-profile proof
   (character + subgroup ledger replacing a 1548-class census) is the model.

The math goal is to explain the sporadic/uniform split. A unifying manuscript over the published /
in-flight papers is the *potential* deliverable, gated on the split being a theorem rather than a
coincidence — that gate is card C589, not an assumption.
