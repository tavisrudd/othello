## C949 common structural object

Both the balanced SR11 core and the Mason comparison produce a nearly
Steiner `3/4`-block geometry whose pair leave consists of three matchings.
For the Mason deficient-block set `U`,

```text
binom(|U|,2)=e_leave(U)+6F_4(U)+3F_3(U)+F_2(U).
```

At the `q^(3/2)` boundary, `|U|` is on the `sqrt(q)` scale and the full
four-block count has positive quadratic density.  Generic regular-design
arguments cannot exploit this: abstract affine countermodels and a genuine
one-vertex Mason deletion both retain dense full blocks.  Any improvement
must use Mason coordinates/additive structure and control the partial
two/three-block boundary in the small-set regime.

The exact mixed-correlation variable missing from scalar moments is

```text
q|B intersect S|
 =sum_ell |B intersect ell||S intersect ell|-|B||S|.
```

An `o(q^(3/2))` attraction theorem for some Mason `S` would contradict the
quantitative gap, but it is a major classification input, not a consequence
of the present moments.
