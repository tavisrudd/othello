# C985 Ergodis cross-domain gem scan

**Lane:** `complete-ports`

**Date:** 2026-08-30

## Decision

Ergodis has credible expansion targets outside coding theory.  The strongest
ones are not generic encodings of an arbitrary search problem.  Each exposes a
small exact continuation state, a theorem-derived quotient, or a compositional
certificate that matches Ergodis's core:

\[
 \text{structured partial object}
 \longrightarrow
 \text{minimal observable interface}
 \longrightarrow
 \text{exact elimination and witness lift}.
\]

The highest external-value target is the real-rooted polynomial enumeration
behind the open equiangular-line maximum in `R^18`.  The highest theorem-fit
target is C80's odd-projective-plane cap game.  The cheapest mechanism test is
the GF(27) bounded-exchange coset-leader compiler.  They should not be started
as one undifferentiated application sweep.

This ranking comes from the current C985 theorem-import backlog, Fable's
commercialization memo, the `gem-mining` and `crowns` handoffs, the open-problem
crosswalks, and the lane discovery tracks.  It is a portfolio-side technical
triage, not a novelty or priority audit.

## 1. Real-rooted prefix compiler for equiangular lines

C1000's recommended attack enumerates real-rooted integer polynomials with
fixed leading coefficients, type-2 modular checks, interlacing decks, and
rational linear-programming exclusions.  That is naturally a compositional
prefix problem.

An Ergodis interface state should retain only data a coefficient continuation
can observe:

- the fixed prefix and remaining coefficient bounds;
- the needed Newton sums and congruence residues;
- the interlacing/root-interval deck;
- the active exact linear inequalities;
- a provenance handle for a Farkas exclusion or completed polynomial.

Two prefixes are contextually equivalent when they admit exactly the same
remaining coefficient completions and certificate outcomes.  Reachable
residue masks can be packed into small bitmaps; sparse decks should use sorted
or succinct sets only after density measurement.  The evidence emitter can
stream each terminal candidate or exact Farkas vector directly to a file, so
the enumerator never buffers the full transcript in memory.

This is the best public application frame because the output is not merely a
faster solve: it is a replayable candidate census and exact exclusion bundle.
However, C1000 explicitly records that its Stage 1 is not approved.  The next
authorized action must therefore be a bounded adapter/design spike or a fresh
approval, not the 200-CPU-hour enumeration.

## 2. C80 as an exact game-state compiler

The cap-game handoff already supplies the right boundary vocabulary: live
vertices, load-one pair-conflict blocks, load-zero capacity-two blocks, and an
exact residual exchange transform that commutes with geometric play.  These
are not ad hoc search features; they are candidate observable interface labels.

For a residual component `X`, define its response by the P/N or nimber outcome
under every legal boundary load and continuation.  Quotient components with
identical responses, compose involution matchings and off-conic blocks, and
retain witness moves.  The existing q=11 falsifier is valuable training data:
it proves that a one-label summary is too coarse.  The q=23 bucket census and
q=25 all-P census are large positive controls.

The ambitious result is a finite or parametrically stable quotient whose
transition laws no longer depend on q except through a small capacity count.
That would turn the uniform odd-plane conjecture into an exact state-closure
theorem.  A negative result is still valuable if it identifies the first
boundary label whose omission merges a P and N context.

## 3. Autocorrelation-state search for Hadamard constructions

The gem-mining record now says order 668 was found without any nontrivial unit
multiplier, while order 2060 uses a genuine CRT multiplier.  Thus a useful
backend cannot assume symmetry; it must exploit it when present and remain
sound when absent.

For a partial sequence tuple, the exact future response is determined by
remaining row sums, partial periodic autocorrelations, orbit/multiplier labels,
and the residual attainable envelope at each shift.  Composition is addition
of correlation contributions with exact reachability intersection.  Dense
small envelopes belong in bitmaps; large sparse frontiers need measured
compressed representations and Pareto dominance.  AVX popcount/XOR kernels
can accelerate leaf verification, but the decisive gain must be state
compression or a moment/Fourier exclusion.

The smallest open admissible Hadamard order recorded by C999 is 2092.  An
unrestricted length-523 search is too large for a first experiment.  Promotion
requires a control where the same compiler reconstructs known pairs and shows
a changed growth curve, not merely a fast verifier.

## 4. Imported general theory

Two portfolio theorems sharpen the proposed Ergodis theory itself.

First, C434's double-coset information lattice realizes an exact chain of
observations through `K\G/H`.  It is a concrete model of progressive interface
projection: coarse state, intermediate shared-edge profile, and decorated
state that lifts back to the object.  This suggests a general compiler API in
which several exact quotient levels coexist and the solver selects the
cheapest level sufficient for the remaining context.

Second, the Schur-closure backlog provides a way to derive observation degree.
Starting from `L`, compile `L`, `L^{\circ 2}`, `L^{\circ 3}`, and stop only when
the observation algebra saturates.  A separating profile proves sufficiency;
a concrete trade proves that two states remain indistinguishable.  Deterministic
automata, B3/H3 matching quotients, and one recovery interface can share this
gate.  This is a plausible route from "choose a state representation" to
"derive the least feature closure that separates all admitted contexts."

## 5. Near-term implementation order

1. Freeze the current CSS performance work and its exact evidence.
2. Specify a small `ContinuationState`/streaming-certificate adapter without
   changing the existing automata or CSS hot paths.
3. Use B3/H3 double-coset levels as the tiny exact hierarchy test.
4. Choose one flagship spike:
   - C80 if theorem fit is the priority;
   - the C1000 polynomial adapter if external open-problem value is the
     priority and its compute gate is freshly approved.
5. Keep GF(27) bounded exchange as the low-risk fallback and regression
   fixture.
6. Do not start order-2092 or the full `R^18` census until the corresponding
   small control changes the growth curve and emits replayable evidence.

## Red-team boundary

- Shared words such as state, quotient, or message passing are not themselves
  a new theorem.
- A domain encoder that hands the unchanged problem to SAT/MIP does not clear
  the Ergodis application gate.
- Symmetry is optional metadata, not an assumed source of compression.
- Approximate learned state is a later fallback only after the exact quotient
  is known on tractable controls.
- Open-problem status and novelty must be re-audited before any public claim.
- Large searches remain separately gated even when the adapter is reusable.

## Highest-EV next move

The highest-EV technical move is the small exact continuation-hierarchy API
with B3/H3 as its first fixture, followed immediately by one flagship adapter.
It is the common stepping stone: it tests the general theory cheaply, avoids a
coding-only frame, and supplies the witness/evidence boundary needed by C80,
real-rooted enumeration, and autocorrelation search.
