## Primary reward C — Capsule and digital twin

### First artifact

Build one offline pipeline:

```text
matrix + radius + placement + failure domains + capacities
    -> complete/lazy repair-port capsule
    -> blockers, cheapest radius, sequential closure/core, capacity prices
    -> replayable plan or impossibility witness
```

The first interface should be a CLI and stable signed schema, not an HDFS/Ceph data-path change.
The digital twin should answer exact counterfactuals about node/rack failures, locally versus
sequentially repaired fractions, mandatory/pivotal helpers, stopping cores, and shared bottlenecks.

- the source model is trustworthy and automatic: a code matrix plus deployment annotations;
- every major output has an exact theorem or certificate owner;
- it can falsify the commercial thesis without operational integration risk; and
- the capsule is reusable by a later controller, systems evaluation, reliability study, or
  representation-sensitive linter.
