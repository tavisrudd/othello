# Major named open problems: generalist index

**Snapshot:** 2026-07-31

This is the high-recognition index requested for broad comparison.  It is not
an assertion that every formulation below is presently open.  The source-set
IDs point to `sources-generalist-major.md`; specialist source catalogues in this
directory remain authoritative where they overlap.

## Status key

- `official-open`: a current official prize/list page marks the stated problem
  open.
- `live-lead`: a recent institutional, society or expert collection treats the
  problem as live, but this pass did not read a definitive status survey.
- `mixed`: the name denotes a family/programme with solved and open forms.
- `disputed`: a claimed proof lacks broad community consensus or the status is
  otherwise contested.
- `refresh`: famous historical entry whose exact modern remainder must be
  audited before use.

Only `official-open` is safe to repeat without a further status check.

## Coverage boundary

This first pass favors names recognizable across fields and canonical source
collections.  It is deliberately not a scrape of every item in Erdos, Arnold,
Kourovka, AIM, TOPP, `K3`, Thurston or the Yau lists.  Those corpora contain
thousands of specialist questions and should be extracted into their own files
when a local result family supplies a plausible keyword or mechanism-level
bridge.

Several entries above say `specialist audit required`; that is an honest queue,
not a citation.  They must not support manuscript claims until an authoritative
source and read depth have been added.
