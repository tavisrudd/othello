## Step 3 — one disposition per item

- **Fold**: add to an existing card (C1194, C1195, C1196, C1197, C1205, C1206, C1207), with the
  exact card edit.
- **Bundle**: a single "small repairs" task for the hours-and-minutes items, with a complete list
  and per-item acceptance, split by repository (core, private) so each half commits on its own.
- **Allocate**: its own task, with a one-paragraph scope; order all proposed tasks by expected
  value against the programme goal and the queued work they unblock.
- **Decide**: a question for Tavis, with a recommendation and short pros and cons, for anything
  that is an architecture choice, a format change or a validation-gate change (at least: contract
  crate split, schema string for the Datalog language, WASM as a target for the Datalog path, an
  ABI for the Datalog path, the domain ceiling, the C1194 evaluator and certificate question).
- **Drop**: not worth doing, with the reason; or **discovery track** where the item is an
  observation rather than work.
