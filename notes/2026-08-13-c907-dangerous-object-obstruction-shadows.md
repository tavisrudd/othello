# C907 — obstructing the dangerous object by its shadows

Date: 2026-08-13

Status: reduction/sieve, not Gold.  The remaining counterobject is not an
ordinary exceptional packet.  It would be an analytic ambient-to-ambient
Stokes shear generated by a connected `c1`-neutral boundary tower and visible
to the rank covector on the primitive-sixth packet.  It can exist only if it
passes every shadow below.

## 1. Obstruction-to-shadow dictionary

| What the object needs | What obstructs it | Cheap shadow that detects the obstruction |
|---|---|---|
| An unbounded family of curve classes with fixed virtual degree | `c1` has one sign on the relevant cone, so no recession direction exists | Mori/Cox charge vector and `ker(c1)` slope |
| A connected compensation between positive- and negative-discrepancy rays | A negative subtree of size `n` needs linearly many flags, while a fixed carrier has bounded boundary contact | Boundary incidence graph plus the valence/contact matrix |
| A state that can actually leave the boundary | Evaluation images are too small, or every one-/two-leg class factors through supported strata | Primary one- and two-leg evaluation pushforwards; finite pair-moment matrix |
| Nonzero rank after leaving the boundary | Window mutations are generated by unstable-stratum objects, all of rank zero on the common open | Numerical `K_0` window quotient and rank row |
| A genuine analytic jump rather than a formal tail | The chosen phase stays in one nonturning chamber, so a zero Stokes coefficient cannot jump | Quantum-spectrum discriminant and anti-Stokes-ray arrangement |
| A jump that changes the primitive-sixth rank Boolean | Euler pairing, the divisor tag `N=1-L`, and triangular zero patterns force the possible Stokes matrix to stabilize the rank row | Finite nullity system `S^T chi S=chi`, `[S,N]=0`, and `rS|P6=r|P6` |
| An analytic action different from the categorical one | The ambient numerical row of the Mellin--Barnes transition agrees with the window row | One-row Stokes/window comparison, not a full Gamma--Orlov theorem |

The attack is conjunctive: killing any row kills the dangerous object.  A
direct construction is unnecessary unless a candidate survives all seven.

There is also a singular replacement for the whole sieve.  If the adjacent
receiver transition factors into elementary Stokes shears whose **target
vectors** are all boundary-supported Gamma classes, then the off-boundary
point/rank row annihilates every target and is fixed by their product.  This
is the rank-zero-target Stokes lemma of
`2026-08-13-c907-rank-zero-target-stokes-lemma.md`.  It is weaker than a full
Stokes/window comparison and, if proved, makes the seven tests fallback
proof tools rather than separate obligations.

## 2. What the object would have to be

The smallest possible geometry is not a center object by itself.  It is a
three-part composite:

1. an off-boundary **carrier** carrying the cubic primitive-sixth state;
2. a connected mixed-sign boundary **propagator** with primitive neutral
   class `delta in ker(c1)` and arbitrarily many multiples `n delta`;
3. a second attachment returning the propagated state to an ambient branch
   with nonzero rank.

A one-legged tail cannot do this if its evaluation state is supported and
the transition is triangular.  The next candidate is a two-legged bridge.
The valence/contact bound says such a bridge cannot be assembled from two
independent long tails: an actual positive-to-negative incidence path is
required inside the boundary.

Analytically, the object is an exponentially small off-diagonal coefficient
in a Stokes matrix.  Categorically, it is invisible on the common open and
rank-trivial in the algebraic window quotient.  Thus any counterexample is
necessarily **categorically phantom but analytically rank-visible**.  This is
the sharp signature to test.

## 3. The first exact suspect and why it is not yet dangerous

The toric charge

\[
 (3,1,1,-1,-1,-1,-2)
\]

arises by blowing up a codimension-two center meeting the negative line of
the point `(1,3)` flip.  It has a connected neutral tower and the scalar
calibration

\[
 {}_3F_2(1,1,\tfrac12;\tfrac13,\tfrac23;4q/27).
\]

It therefore passes the cone and incidence shadows.  But every map in the
tower is supported on a fixed nodal boundary curve.  The one-leg moduli has
virtual dimension three and evaluation image of dimension at most one; the
two-leg moduli has virtual dimension four and image in a surface.  Its
primary one- and two-leg pushforwards vanish.  The hypergeometric series is a
descendant/equivariant calibration shadow, not a primary ambient coupling.

So the first exact suspect is ruled out at the primary low-moment shadow.  A
replacement must explain exactly how a relative or descendant gluing state
enters the small ambient quantum connection despite that dimension deficit.

## 4. Likely suspects already ruled out

- A pure exceptional, C908 theta, Fano-center, or ordinary-flop packet fails
  the support/window-rank shadow.
- Two independent positive and negative tails fail the contact-budget
  shadow.
- A neutral toric tower supported on a fixed curve can pass cone/incidence
  but fail the primary moment shadow, as above.
- A formal `O(z)` tail is not itself a counterobject: without a turning wall
  or a permitted nullity-system shear it has no analytic mechanism to change
  the rank Boolean.
- Bare Barnes coefficients do not supply an integral shadow because the
  relevant formal branches have independent nonzero normalizations.

No known candidate passes the primary-moment, turning, and Euler/divisor-tag
shadows simultaneously.

There is an exact spectral impossibility behind this separation.  By the
genus-zero divisor equation, a class `gamma` contributes to `c1 star` with a
factor `c1.gamma`.  Hence every pure neutral class `n delta`, with
`c1.delta=0`, contributes zero to the irregular leading operator of the
small `z`-connection.  It cannot create an exponential or turning ray.  Only
the carrier-dressed affine tower `beta_0+n delta` survives this lemma; see
`2026-08-13-c907-pure-neutral-spectral-invisibility.md`.

## 5. Bounded attack

1. Enumerate mixed-sign two-circuit toric normal models in dimension five
   and compute their primitive `ker(c1)` slopes.
2. Reject models with no connected incidence path or insufficient contact
   valence.
3. Compute primary one-/two-leg evaluation moments.  Stop at zero.
4. For survivors only, compute the turning discriminant and the numerical
   window row.
5. Solve the Euler/divisor-tag nullity system for a rank-changing shear.
6. Use Mellin--Barnes analysis only for the finite residue left by steps
   1--5.

This is the imported shadow strategy: reconstruct or exclude the hidden
object from sparse, cheaper invariants.  Gold follows if the finite survivor
list is empty; a nonempty list gives an explicit, minimal target rather than
an unspecified analytic compatibility theorem.

## EJ / TT / AA

- **EJ:** the dangerous object is a connected neutral two-leg propagator,
  not an exceptional summand.
- **TT:** a descendant hypergeometric tail is not evidence of primary
  carrier coupling; evaluation-dimension must be checked first.
- **AA:** the best attack is the ordered seven-shadow sieve above.  The first
  exact neutral toric suspect dies at shadow three, so the search has already
  become strictly smaller than the original Stokes problem.
