# Untracked-path citation audit (2026-09-13)

**Lane**: audit, read-only. No file other than this report was modified.

## Rule under audit

A task report, handoff, queue row or evidence bundle must never cite an artifact under
`~/.cache` (equivalently `$HOME/.cache`, `/home/tavis/.cache`), `/tmp` other than the
ZFS-backed `/tmp/persistent`, or any other untracked local path as evidence, as a replay
input, or as a reproducibility-bundle row. Naming such a path as a workspace convention
("builds go to `~/.cache/ergodis/target/`", "the spike worktree is `~/.cache/ergodis/worktrees/c1153/`")
is not an infraction.

## Scope and method

Files changed in git in the last seven days, markdown only:

- `~/src/othello`: everything under `notes/` (including `notes/handoffs/`), 346 files.
  The three already-repaired reports (`notes/2026-09-13-c1183-ranked-certificate.md`,

and `retained (harness|binary|executable)`. That produced 440 candidate lines, every one of
which is classified below.

## Verdicts used

- **infraction** — the path is cited as the evidence for a claim, as the thing to run or read
  for replay, or as a row in a hash-bearing bundle.
- **convention** — the path names where builds, worktrees, module caches, server PID/log files
  or command output sinks live, or the line is a policy statement about such paths. Also used
  for a replay whose untracked output is immediately compared against a committed expected
  file, and for wording that mentions a retained binary without citing a path when the hash and
  source commit are in a committed receipt.
- **audit finding** — the line is a review reporting someone else's leaked path. Nothing to fix
  in that file; the fix belongs in the file it reports on.

Infractions carry a class, because the repair differs:

| Class                              | Repair                                                                                                           |
|------------------------------------|------------------------------------------------------------------------------------------------------------------|
| `run-quiet log`                    | Cite the tracked gate command plus the commit it ran at; paste the load-bearing tail into the committed report.   |
| `Lean build run`                   | Cite the Lean module, the commit, and the guarded `lean-build-queue.py` invocation; paste the axiom/status output. |
| `retained binary`                  | Cite repository, commit and build recipe, with the SHA-256 in a committed receipt.                                |
| `build product`                    | Cite the commit and `cargo build` command; the target directory stays a convention, not a citation.               |
| `cache data/report`                | Commit the measurement JSON, receipt or screenshot digest under `evidence/`/`analysis/` and cite that path.       |
| `session scratchpad`               | Cite the tracked generator and commit, or a `/tmp/persistent/tavis/lit-search/` key.                              |
| `temp file`                        | Cite a tracked path, or a `cmp` against a committed expected file.                                                |
