# Codex Lemma 4 check (2026-07-07)

## Result

The cyclic Lemma 4 in `2026-07-04-sumfree-game-theorem.md` is false as a standalone statement
unless it excludes the extra move

```text
z = t + n/2
```

when `n` is even and `n/2` is not already one of the fixed extras.

Machine search found exactly that breaker shape through `n <= 120`. With the corrected hypothesis
`z != t + n/2`, the same search found no breakers. The `n = 3 mod 6` control also found no
breakers.

This does not invalidate the cyclic theorem's actual uses:

- In the `n = 3 mod 6` case, there is no order-2 element `n/2`, so the bad point is unavailable.
- In the `n = 0 mod 6` case used for the `{n/2, n/3}` residual position, `n/2` is already in `E`,
  so `z = t + n/2` is not legal: with `m = n/2`, the triple `z + t = m` is already present after
  adding `z`.

The theorem note should still correct Lemma 4 as stated, because the displayed lemma allows
`E = {t}` while an order-2 element exists.

## Breaker family

Let `n = 6k`, `t = n/3 = 2k`, `m = n/2 = 3k`, and choose `E = {t}`. With symmetric support
`S = empty`, set

```text
z = t + m = 5k
w = -z = k
```

Then `{t, z}` is sum-free and `z` avoids `{0, m, t, 2t}`, but adding the mirror reply `w` creates

```text
w + w = t.
```

The smallest instance is `n = 6`: `t = 2`, `m = 3`, `z = 5`, `w = 1`. The task queue listed the
same shape at `n = 12`: `t = 4`, `m = 6`, `z = 10`, `w = 2`.

## Why the support bound is exhaustive

The brute-force half enumerates symmetric supports `S = -S` with `|S| <= 4`.

That is enough for a breaker search. If `C = E union S` is sum-free, `C union {z}` is sum-free, but
`C union {z, -z}` is not, then some single bad Schur triple uses the newly-added point `-z`; all
other points of `S` are irrelevant to witnessing the failure. Remove every symmetric pair in `S`
that is not used by that bad triple. This preserves:

- symmetry of `S`;
- the fixed extras `E`;
- sum-freeness of `C`;
- legality of `z`;
- illegality of the mirror reply.

The remaining bad triple contains `-z` and at most two non-extra points from `S`, and symmetry keeps
at most their two negatives as well. Hence every breaker has a reduced breaker with `|S| <= 4`.

The separate witness-support pass implements this reduction directly by ranging over all possible
bad triples involving `-z`, then checking the reduced symmetric support. It gives the same answer
as the brute-force bounded enumeration.

## Abelian-note audit

`2026-07-05-sumfree-abelian-theorem.md` says the `r3 <= 1` cases lift the cyclic Lemmas 1-4
"verbatim", and it invokes cyclic Lemma 4 in two direct cases:

- `s2 = 1`, `tau3 = 1`, `r3 = 1`: uses `E = {m, t}`.
- `s2 = 0`, `tau3 = 1`, `r3 = 1`: uses `E = {t}` but has no order-2 element.

Read as a general imported lemma allowing arbitrary `E subset {m,t}`, the abelian lift inherits
the same missing hypothesis. In any abelian group with a unique order-2 element `m` and one
order-3 pair `{t, -t}`, the position `E = {t}`, `z = t + m`, `w = -z` has the same failure:
`w + w = t`.

The direct abelian outcome arguments in the note do not use that bad configuration:

- In the unique-order-2 plus one-order-3 case, the proof uses `E = {m,t}`, and `z = t + m` is
  already illegal because `z + t = m`.
- In the no-order-2 plus one-order-3 case, no `m` exists.

So the prose theorem cases appear safe, but the phrase "verbatim lift of cyclic Lemmas 1-4" should
be read only after correcting Lemma 4, or restated with the corrected exclusion.
