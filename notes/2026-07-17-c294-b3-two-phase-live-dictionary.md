# C294 B3: two-phase live dictionary

**Date:** 2026-07-18

**Lane:** `crowns`

**Status:** exact checkpoint reuse advances the bounded frontier, but the separator quotient adds
no traversal reduction beyond an uncompressed dictionary and still returns no q=5 value

## Result

The fixed recursive-separator partition can be compiled into an immutable live dictionary without
changing the exact traversal. On the q=5 type-0 training prefix, 84,964 completed absolute keys map
to 84,018 checked value classes. A fresh recursion with a second 100,000-new-state cap serves
681,569 dictionary hits and advances the first unseen connected state from 24 to 30 vertices, but
still does not return the 116-vertex follower nimber.

This is a useful checkpointing result and a bounded negative for the present quotient. An exact
dictionary with one stored value per absolute key and the compressed dictionary produce identical
phase-two values, misses, hits, decompositions, new-cache hits, key requests, stop state, and
frontier. Compression changes only the number of stored value classes:

| domain | absolute keys | compressed classes | classes touched, exact | classes touched, compressed | phase-two dictionary hits | value |
|:--|--:|--:|--:|--:|--:|--:|
| q=3 type 0 | 49 | 46 | 1 | 1 | 1 | 1 |
| q=5 type 0, 100,000-state training plus 100,000-new-state replay | 84,964 | 84,018 | 8,984 | 8,918 | 681,569 | unknown |

Thus 66 fewer value classes are touched in the compressed replay, but no recursive call is avoided
that would not also be avoided by the exact checkpoint dictionary. The 946-class offline reduction,
including its three genuine transition mergers, remains too weak to justify the ten-million-state
run or evaluation of the other six hard types.

## Two-phase construction

Phase one is the unchanged recursive-separator normal-form traversal. Every newly completed
absolute quotient key now also retains its insertion class ID. This bookkeeping does not alter the
partition or values; byte-for-byte regeneration of both predecessor q=3 and q=5 JSON certificates
confirms that point.

The compiler path-compresses the predecessor union/find relation, assigns dense class IDs, and
checks that every absolute key in one dense class has the same nimber. The exact control dictionary
instead assigns one class to every absolute key. Phase two restarts the component recursion. After
constructing the same intrinsic absolute key, it first consults the immutable dictionary; only a
miss enters a fresh exact cache and mex recursion. The compressed and exact dictionaries are then
run separately from the same emitted graph, and the executable fails if their traversal metrics or
results differ.

This compilation is sound on the recorded domain because a hit is admitted only for an absolute
key completed in phase one, and the compressed class relation is generated by graph isomorphism or
the proved complete two-port replacement interface with zero value conflicts. It does not infer a
class for any unseen absolute key.

## Finite measurements

The q=3 control reproduces 108 training states, 680 decompositions, and follower nimber 1. Both
dictionaries return that value with one lookup and no new connected-state evaluation. The
independent connected-K-set certificate also gives follower nimber 1.

For q=5, phase one exactly reproduces the predecessor's 100,000 states, 1,946,240 decompositions,
84,964 absolute classes, 84,018 normal classes, zero value conflicts, and 24-vertex stop frontier.
Phase two evaluates another 100,000 connected states, serves 681,569 learned hits, performs
2,166,160 decompositions, and stops at the first unseen 30-vertex state. The higher frontier is a
real continuation benefit, but the combined experiment has spent 200,000 newly evaluated states.
It is not a claim that 100,000 total states reach 30 vertices, nor evidence of a q-uniform finite
quotient.

## Independent checks and trusted boundary

The compressed replay is checked against an exact per-absolute-key dictionary inside the C++
executable; the two traversals agree in every load-bearing metric. The separate Python audit checks
that equality from the emitted certificates, checks all class-count identities and stop
conventions, and imports the independently organized q=3 connected-K-set result. The predecessor
q=3 and q=5 normal-form outputs regenerate byte-identically after the class-ID instrumentation.

There is no independently implemented full q=5 dictionary traversal. Its trusted boundary is the
predecessor graph generator, component and absolute-key canonicalizers, mex/xor recursion,
recursive-separator union/find closure, dense dictionary compiler, and equality of complete vector
keys. In particular, the Python audit independently checks certificate consistency, not the
681,569 individual C++ lookups.

The result certifies only reuse of the fixed type-0 prefix. It does not return a hard q=5 value,
show that the three genuine transition mergers are encountered in phase two, establish useful
compression for unseen states, or justify a larger state cap. The next B3 design must enlarge the
exact generator closure enough that the compressed live replay materially improves on its exact
dictionary control; generic rolling checkpoint continuation alone is not the missing game-aware
quotient.
