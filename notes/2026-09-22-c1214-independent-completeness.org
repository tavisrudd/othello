* Design and red team

** Accepted implementation boundary

Replace the ranked checker's call to shared trace completeness with a private
module. Keep witness/rank validation separate. The new pass independently
computes prefix binding masks, matches constants and repeated variables,
maintains binding snapshots, and packs each implied head. The final traversal
dispatches once per rule to body lengths 1–4, then uses bounded nested loops
and local eight-variable parent/child snapshots. Rule and body order remain
the source order. The first atom scans its relation; subsequent atoms
use compound indexes. Prepare required indexes per rule before its traversal.

Compile each atom's constant checks, first variable assignments and equality
checks into fixed capacity arrays before traversal; classify source slots once.
Compile head constants and variable radix coefficients separately. This avoids
reinterpreting rule syntax for every candidate and keeps the semantic helpers
independent of the trace checker. The maximum four-column packed key remains
=u64::MAX=; do not compute an unused fifth radix power.

This is independent implementation, not algorithmic diversity. Shared trust
remains in source admission, tuple storage, membership, CSR index construction,
index probing and its key computation. Ranked support checking also retains
shared helpers. A storage/index bug that drops candidates can still correlate
both completeness verdicts. No formal soundness claim follows from tests.

The new source module must join the verifier identity's hashed source list;
its list-domain tag advances. Certificate grammar and prepared source identity
remain unchanged. Existing verification records continue identifying the old
checker implementation rather than silently naming the new one.

** Invariants

1. Each loop level owns its parent binding snapshot; failed rows and descendants
   cannot leak bindings into siblings.
2. Candidate enumeration includes every tuple consistent with the bound
   columns. The independent matcher checks every slot, including constants
   and equality between repeated occurrences of a variable.
3. Every variable used in an implied head is bound after a complete body match,
   by admission's range restriction. Head packing follows domain radix order.
4. At a leaf, check membership without opening a fifth loop level. Empty relations
   exhaust normally. Keep original rule order for =Incomplete(first_rule)=.
5. Allocate indexes before traversal. The real traversal runs repeatedly under
   an allocation counter and uses fixed capacity state.

** Fermi estimate and rejected scope

The first Sol proposal dynamically chose the smallest remaining atom and used
single-column indexes. Astra conditionally accepted its correctness design but
identified a multiplicative enumeration risk: individual column buckets can
be large when their conjunction is selective. Existing binarized triangle
programs provide a bounded ternary-relation stress case.

Primary and Astra selected the narrower source-order compound-index design
before production implementation. It preserves candidate sets, traversal
order, index requirements, and asymptotic work. It still needs measurement:
uniform frame handling and independent matching can change instruction count
and constant factors. No speedup is predicted or claimed. Dynamic planning,
extra indexes and fully populated-head shortcuts are outside this increment.
