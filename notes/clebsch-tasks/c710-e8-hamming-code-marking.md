**Lane:** `clebsch`

**Status:** queued after C708 and the C705 common-source gate

## Objective

Determine whether C682's Klein--McKay \(E_8\) return and the classical
Construction-A realization of \(E_8\) from the extended binary Hamming code
admit one compatible marking that also carries the Clebsch conference
operator and C705 sister geometry.

## Gates

1. Fix both integral \(E_8\) models and an explicit lattice isometry.
2. Locate the six-axis, \(15/10/6\), and golden conference data in the
   Construction-A coordinates.
3. Test whether the relevant binary residue is the Hamming code, a
   shortening/puncturing, or no distinguished code at all.
4. Compare bad-prime and discriminant behavior with C682/C705.
5. Require an explicit simultaneous lift; shared use of the name \(E_8\) is
   not evidence.

identification.  A code claim requires an explicit lattice marking.
