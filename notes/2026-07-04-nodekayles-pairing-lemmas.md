# Node-Kayles pairing certificates — the abelian-Cayley core

**Date:** 2026-07-04. Clean lemma bundle extracted from
[game (a): Cay⁺(Z_n,S) outcome law](2026-07-04-cayley-nodekayles-outcome-law.md) (which discovered
and machine-verified them). This note states the reusable, proof-on-write core: one master pairing
lemma at full graph generality, then the abelian-Cayley specializations **R0 / L1 / L2** and the
odd-order impossibility. These are the P-side (second-player-win) tools for GRAPH Node-Kayles; they
transfer verbatim to any abelian Cayley graph (circulants, the torus `Z_m × Z_n`, king/rook graphs)
and — for the master lemma — to any vertex-transitive graph (Petersen, Kneser, …).

## Setup

**Graph Node-Kayles** on a finite simple graph `G = (V, E)`: players alternately pick vertices
forming an **independent set** — each new vertex is distinct from and non-adjacent to all previously
chosen vertices. Equivalently, playing `v` deletes its closed neighborhood `N[v] = {v} ∪ N(v)` from
the pool of available vertices. **Normal play**: the player unable to move loses. `G(G)` denotes the
Sprague–Grundy value of the start position (all of `V` available); the start is a **second-player
win iff `G(G) = 0`**.

For a finite abelian group `Γ` and a symmetric connection set `S = −S`, `0 ∉ S`, the **Cayley graph**
`Cay(Γ, S)` has vertex set `Γ` and edges `{u, v}` with `v − u ∈ S`. Every group translation
`τ_g : x ↦ x + g` and the negation `ν : x ↦ −x` (the latter because `S = −S`) is a graph
automorphism. `Cay(Γ, S)` is vertex-transitive, so `G(Cay(Γ,S)) ∈ {0, 1}` (all first moves are
isomorphic ⇒ the root option multiset is a singleton ⇒ mex ∈ {0,1}).

## The master lemma

A **closed pairing** of `G` (a.k.a. a safe pairing) is a fixed-point-free involutive automorphism
`σ` of `G` with `{v, σ(v)} ∉ E` for every `v` — i.e. `σ` has no fixed vertex and no vertex is
adjacent to its mate.

> **Lemma P0 (whole-graph pairing ⇒ P).** If `G` admits a closed pairing `σ`, then `G(G) = 0`.

*Proof.* The second player mirrors: maintain the invariant that after each of the second player's
replies the played set `A` is `σ`-invariant (`σ(A) = A`) and independent. This holds initially
(`A = ∅`). When the opponent plays a legal `v` (so `v ∉ A`, `v` non-adjacent to `A`), the second
player answers `σ(v)`. Then:

- `σ(v) ≠ v` (fixed-point-free);
- `σ(v) ∉ A`, else `v = σ(σ(v)) ∈ σ(A) = A`, contradiction;
- `σ(v)` is non-adjacent to `v` (closed pairing);
- `σ(v)` is non-adjacent to `A`: `σ` is an automorphism with `σ(A) = A`, so `σ(v) ∼ a` for some
  `a ∈ A` would give `v ∼ σ(a) ∈ A`, contradicting `v` legal.

So `A ∪ {v, σ(v)}` is independent and `σ`-invariant — the invariant is restored, and the second
player always has a legal reply. The game is finite, so the opponent runs out of moves first; the
second player makes the last move and wins. ∎

> **Corollary P0′ (move-and-mirror ⇒ N).** If some vertex `u` has a residual `G − N[u]` that admits
> a closed pairing, then `G(G) ≠ 0` — the first player plays `u`, then mirrors. If `G` is
> vertex-transitive, `G(G) = 1`.

*Proof.* Playing `u` moves to the Node-Kayles game on `G − N[u]`, which is a P-position (value 0) by
P0. The root thus has an option of value 0, so `G(G) = mex(…) ≠ 0`. For vertex-transitive `G` the
root lies in `{0,1}`, hence `= 1`. ∎

> **Odd-order impossibility.** A fixed-point-free involution partitions `V` into transpositions, so
> it forces `|V|` even. Hence **no graph on an odd number of vertices has a closed pairing**, and
> every P-position on an odd-order vertex-transitive graph is won by genuine strategy, not by a
> whole-graph mirror. (Smallest witness: `C₅ = Cay(Z₅, {±1})`, `G = 0`, unpairable.)

## The abelian-Cayley specializations

Fix a finite abelian `Γ`, `S = −S`, `0 ∉ S`.

> **R0 — index reduction.** Let `H = ⟨S⟩ ≤ Γ` be the subgroup generated by `S`, and
> `m = [Γ : H]`. Then `Cay(Γ, S)` is `m` disjoint copies of the **connected** Cayley graph
> `Cay(H, S)` (one per coset of `H`), so by Sprague–Grundy XOR
> ```text
>   m even  ⇒  G(Cay(Γ,S)) = 0
>   m odd   ⇒  G(Cay(Γ,S)) = G( Cay(H, S) )   (a connected Cayley graph)
> ```
> Every abelian-Cayley outcome reduces to a connected one, with even coset-multiplicity
> automatically P.

*Proof.* Cosets of `H` are the connected components (edges stay within a coset since `S ⊆ H`), each
isomorphic to `Cay(H,S)` by translation. XOR of `m` equal Grundy values is `0` for `m` even,
else the common value. The `m`-even case is also a direct P0 instance: swapping two whole cosets is a
closed pairing. ∎

For `Γ = Z_n`: `H = (d)` with `d = gcd(n, s : s ∈ S)`, `m = d`, and each component is
`Cay(Z_{n/d}, S/d)` — this is R0 exactly as stated in the outcome-law note.

> **L1 — involution-translation pairing (even order).** If `Γ` has an element `g` of order 2
> (`2g = 0`, `g ≠ 0`) with `g ∉ S`, then `τ_g : x ↦ x + g` is a closed pairing, so `G(Cay(Γ,S)) = 0`.

*Proof.* `τ_g` is a Cayley automorphism, fixed-point-free (`g ≠ 0`), involutive (`2g = 0`); mates are
non-adjacent because `(x + g) − x = g ∉ S`. Apply P0. ∎ An order-2 element exists iff `|Γ|` is even
(Cauchy); for `Z_n` even it is `g = n/2`. **So any `Cay(Γ,S)` with `|Γ|` even that omits at least one
involution from `S` is a second-player win.**

> **L2 — negation steal (odd order, doubling-closed).** If `|Γ|` is odd and `2S = S` (equivalently
> `S` is closed under halving), then the first player plays `0` and negation-mirrors: the residual
> `Cay(Γ,S) − N[0]` (induced on `Γ ∖ ({0} ∪ S)`) has the closed pairing `ν : x ↦ −x`, so it is P and
> `G(Cay(Γ,S)) = 1`.

*Proof.* `ν` is a Cayley automorphism (`S = −S`) fixing `{0} ∪ S` setwise (`−0 = 0`, `−S = S`), so it
restricts to an automorphism of the residual. It is fixed-point-free there (`ν(x) = x ⇒ 2x = 0 ⇒
x = 0`, and `0` is deleted — `|Γ|` odd has no other 2-torsion). Mates are non-adjacent: `x ∼ −x ⇔
2x ∈ S`; but `2S = S` with doubling bijective (odd order) gives `{x : 2x ∈ S} = S`, and residual
`x ∉ S`, so `2x ∉ S`. Apply P0 to the residual, then P0′. ∎ For `Z_n` odd, Paley `p ≡ 1 (mod 8)` is
the case `2 ∈ QR ⇒ 2·QR = QR`.

## Two corollaries used elsewhere

- **Interval family, even `n` (C_n^k).** `C_n^k = Cay(Z_n, {±1, …, ±k})` with `k < n/2`. For even
  `n`, `n/2 ∉ S`, so **L1 gives `G = 0` for every even `n`** — the entire even-`n` interval family is a
  second-player win. (Odd `n` reduces to the octal game `0.[1×k][3×k]7`; see the outcome-law note.)
- **Paley `p ≡ 1 (mod 8)`.** `Paley_p = Cay(Z_p, QR)`; `2 ∈ QR` ⇒ `2·QR = QR` ⇒ **L2 gives `G = 1`**.
  (The `p ≡ 5 (mod 8)` conjecture lives in the N-side gap below and needs the character-sum route.)

## Scope — what these certificates do and do not settle

These are fundamentally **P-side tools**. The empirical picture from the full symmetric-`S`
enumeration (outcome-law note, sound over `n ≤ 20`/`19`):

- **P-positions (`G = 0`)** on **even** `n` are pairing-explained for a large majority (L1 covers the
  `n/2 ∉ S` half; R0-even and affine reflections cover more). On **odd** `n`, **no** P-position is
  pairing-certifiable (odd-order impossibility) — those wins are genuinely strategic.
- **N-positions (`G = 1`)** are pairing-certified (via P0′/L2) only for a **minority** at every `n`
  (e.g. `n = 16`: 1 of 45). Most circulant first-player wins have **no** affine-pairing certificate;
  they win for a deeper `mex > 0` reason. This is why the Paley `p ≡ 5 (mod 8)` conjecture — an N-side
  statement with no pairing — resists a mirror proof and needs Weil-closure machinery.

So the open surface is the **N-side certificate**: what structural object certifies the majority of
circulant first-player wins (a potential function à la Erdős–Selfridge is the research-shaped lever).

## Relation to the sum-free game (b)

The same two mirrors reappear in the HYPERGRAPH Node-Kayles setting of the
[sum-free achievement game](2026-07-04-sumfree-game-theorem.md): its **negation mirror** (Lemma 1
there) is L2's cousin and its **translation mirror** (Lemma 2, `τ_{n/2}`) is L1's cousin. The
difference is bookkeeping — the Schur 3-uniform hypergraph adds obstructions (the fixed point `n/2`,
the collision pair `{n/3, 2n/3}`) that a graph has none of, which is why the sum-free outcome is a
mod-6 law rather than a one-line pairing. This bundle is the graph-case skeleton of that argument.

## Reuse targets

- **Torus / king / rook Node-Kayles** (`Γ = Z_m × Z_n`): R0 (index parity), L1 (any order-2 element
  `(m/2, 0)`, `(0, n/2)`, `(m/2, n/2)` not in `S`), and L2 (odd `mn`, doubling-closed `S`) apply
  verbatim — a first-pass outcome map before any search.
- **Any vertex-transitive graph** (Petersen, Kneser, generalized Petersen): P0 / P0′ / the odd-order
  impossibility hold without a group structure — look for a closed pairing (or a move-and-mirror
  vertex) directly.
