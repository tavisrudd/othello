## Prose lemma

Let `V = F_q x F_q`, with `q != 4` for the rook-graph classification step. A grid-game
hypergraph automorphism is a bijection `phi : V -> V` preserving:

1. illegal pairs: two cells share a row or column;
2. illegal triples among row/column-legal cells: three cells are affine-collinear.

First, preserving illegal pairs means `phi` is an automorphism of the rook graph
`K_q square K_q`, whose vertices are grid cells and whose edges join same-row or same-column
cells. For `q != 4`, the maximal cliques of this graph are exactly the rows and columns, and the
clique-intersection pattern distinguishes the two parallel classes up to exchange. Hence every
such `phi` has the form

```text
(r,c) -> (R(r), C(c))
```

or

```text
(r,c) -> (R(c), C(r))
```

for permutations `R,C` of `F_q`.

It remains to use collinearity. Consider the unswapped case; the swapped case is the same after
exchanging coordinates. A non-axis affine line with slope `m != 0` is

```text
L_{m,b} = { (x, m x + b) : x in F_q }.
```

Every three-point subset of `L_{m,b}` is an illegal triple, so its image under `phi` lies on a
non-axis affine line. For `q >= 5`, this forces the whole set

```text
{ (R(x), C(m x + b)) : x in F_q }
```

to be a non-axis affine line. Thus for every `m != 0` and `b`, there exist `A(m,b) != 0` and
`B(m,b)` with

```text
C(m x + b) = A(m,b) R(x) + B(m,b)  for all x.
```

Taking `m = 1`, `b = 0` gives `C(x) = A R(x) + B`. After absorbing affine output scalings and
translations, the remaining condition is that `R` maps affine lines in `F_q` to affine lines in
`F_q`; equivalently, the induced permutation of the affine line is semilinear. This is the
one-dimensional form of the fundamental theorem of affine geometry as applied inside `AG(2,q)`:

```text
R(x) = alpha sigma(x) + s,
C(x) = beta  sigma(x) + t,
```

with a single field automorphism `sigma`.

The same `sigma` must occur in both coordinates. A "twisted" map

```text
(r,c) -> (a sigma(r)+s, b tau(c)+t)
```

with `sigma != tau` would send a line `c = m r + b0` to

```text
c' = b tau(m sigma^{-1}((r'-s)/a) + b0) + t,
```

which is not affine-linear in `r'` unless `tau sigma^{-1}` is the identity. Therefore
`tau = sigma`. This gives exactly the maps generated by `all_autos`.

For the load-bearing q=11,13,17 cases, `q` is prime, so `sigma` is only the identity and the
enumerated group has size:

```text
2 * (q - 1)^2 * q^2
```

including identity. This matches the note's q=11 count `24,199` nonidentity maps:

```text
2 * 10^2 * 11^2 - 1 = 24,199.
```

```text

```

swap` for `q=5`, filters to those preserving the set of all non-axis collinear triples, and compares
the surviving permutation set to the solver's prime-field `all_autos` formula.

## Why q=7 was not run

The same brute-force check at q=7 would start from:

```text
2 * (7!)^2 = 50,803,200
```

rook-graph maps, before checking `1,470` non-axis collinear triples per candidate. That is not a
small side check while the box is already running the q=19 `esc` validation. The q=5 exact check is
the requested tiny brute-force sanity check; the proof above carries the q=11,13,17 load.
