# C966 -- remaining cubic-threefold algorithmic implications triage

**Lane:** cubic-threefolds

**Status:** later triage after C965; no implementation or manuscript promotion
is authorized by this card

## Goal

Run one bounded, source-aware triage of the algorithmic implications not owned
by C963's cancellation workbench or C965's automated descent engine. Rank them
by theorem readiness, genuine reuse beyond the motivating examples,
implementation cost, certificate quality, and likely mathematical payoff.

## Candidates

1. **Broader constructive stable-rationality solver.** Determine the largest
   honest input class for which Cox/torsor data can be compiled to explicit
   stabilized parametrizations, and separate supplied-structure algorithms
   from any general decision problem.
2. **Exact stabilization-level certificates.** Assess a portable certificate
   pairing a lower obstruction with localized mutually inverse maps for the
   upper bound, deduplicating the map layer already owned by C963.
3. **Modular recognition of special fibres.** Test whether elliptic
   two-division/discriminant resolvents, cusp data, and orbit ideals give a
   reusable recognition algorithm for symmetric members of one-parameter
   families beyond the `A_5` cubic pencil.
4. **Integral lattice algorithms for cycle questions.** Assess saturation,
   Smith-form, primary-defect, and minimal-class membership certificates for
   symmetric intermediate Jacobians and related principally polarized abelian
   varieties.
5. **Reusable computational-birational certificate protocol.** Identify what
   remains after adopting C963's straight-line and localization schema:
   independent checker separation, corruption tests, manifests, and reviewer
   presentation that could transfer to other papers.

## Deliverables

1. A claim/input/output/evidence matrix for the five candidates, explicitly
   marking overlap with C958, C963, and C965.
2. A bounded source and prior-art check sufficient to distinguish a research
   contribution from routine software packaging; no global novelty verdict is
   required for triage.
3. At most one small feasibility probe per candidate, using existing exact
   artifacts. No new census, manuscript edit, public release, or broad software
   architecture is authorized.
4. For each candidate, a verdict of promote, merge into an existing task,
   discovery-track only, or close, with the exact theorem/evidence gap and a
   proposed bounded scope for any promotion.
5. A final EV ordering. Concrete successor IDs are allocated only after the
   user approves promotion; this task must not pre-allocate them.

## Acceptance gate

- Every candidate is assessed against the same explicit criteria and current
  frozen results rather than enthusiasm or generic application language.
- No candidate duplicates C963 or C965 under a new name.
- Applied claims distinguish symbolic exact computation from practical
  numerical efficiency, finite-field use, cryptography, or a general
  rationality algorithm.
- The triage ends with bounded recommendations and closure reasons, not five
  silently opened research programmes.

## First action after C965

Build the overlap matrix first. Close or merge any candidate whose full useful
content is already delivered by C963 or C965 before running a feasibility probe.
