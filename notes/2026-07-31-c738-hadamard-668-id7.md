## Orbit obstruction

The published stable ID 7 is

```text
H = <73,112> = {1,73,112,184,223,295} <= (Z/333Z)^*.
```

Let `u` be an `H`-invariant sign sequence and let

```text
D_u(s) = #{x in Z/333Z : u(x) != u(x+s)}.
```

For every `x = 1 (mod 3)`,

```text
112*x = x+111 (mod 333),
```

and for every `x = 2 (mod 3)`,

```text
223*x = x+111 (mod 333).
```

Both multipliers belong to `H`.  Hence `u(x)=u(x+111)` at all 222
nonmultiples of 3.  Only the 111 multiples of 3 can contribute to the Hamming
distance, so

```text
D_u(111) <= 111.
```

On the other hand, periodic autocorrelation and Hamming distance satisfy

```text
PAF_u(s) = 333 - 2 D_u(s).
```

If two such sequences `a,b` formed a Legendre pair, then at every nonzero
shift, and in particular at 111,

```text
-2 = PAF_a(111)+PAF_b(111)
   = 666 - 2(D_a(111)+D_b(111)),
```

which requires `D_a(111)+D_b(111)=334`.  Multiplier invariance instead gives
the upper bound `222`.  Equivalently, the joint PAF at shift 111 is at least
222, not `-2`.  This contradiction excludes ID 7 without a solver.

The mechanism is a reusable orbit-lock criterion: if a proposed common
multiplier action places `x` and `x+s` in the same orbit on enough positions,
then the maximum joint Hamming distance at `s` can fall below `n+1`, which is
forced for a Legendre pair of odd length `n`.
