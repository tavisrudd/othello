* Work plan

** R6 — explicit validation command matrix

Primary owns a private contributor script under =notes/scripts/= and this
report. Inventory root defaults/all-features, the separately enabled native
module host, canonical browser workflow, and each of nine independently built
provider packages for native and wasm32. Keep provider features separate so
feature unification cannot disguise a missing family build.

The opt-in runner must execute actual commands, record repository revisions,
dirty state, toolchain, command exit status and logs, show unselected rows as
skipped, and label compile-only checks separately from execution. The browser
row orders locked check, fresh build, tests and smoke; a failed build must stop
that row before stale artifacts can be tested. Record generated artifact hashes.
An ignored module recipient test remains an explicit integration gap until its
separate package/transcript fixture is supplied. No support matrix cell becomes
native execution coverage merely because it compiles or runs as WASM.

** R7 — checker mutations, C1214 milestone a

A Sol agent owns only checker integration tests. Start with the delivered
prepared-source byte-door fixtures. Compute expected tiny closures with an
independent bounded oracle, not either production completeness pass. Add exact
rejection checks for isolated support/rank, missing/extra/duplicate fact,
premise/index, source-binding, n-ary and decoder-bound mutations across both
certificate formats. Each valid control must pass first; each mutation must
reach its intended check. State finite scope and missing cases.

Primary reviews the test oracle, mutation discriminators and coverage ledger,
then runs the focused tests and existing core gates and regenerates the source
manifest in the same commit. Production checker changes require a separate
decision if a test exposes a real defect. C1214 milestone b remains open; tests
do not establish algorithmic independence or formal soundness.

** R8 — validated-state API audit, initial C1215 slice

A second Sol agent inventories constructors and trust assumptions behind
admitted/certified/verified types, including external re-admission and trusted
in-process paths. Distinguish a violated documented precondition from unsafe
acceptance of external bytes. Propose bounded regression tests at the concrete
boundaries; avoid colliding with R7's checker tests. Report source ownership,
indexing and staged-frontend invariants explicitly.

Opaque types, builder migration, instrumentation features and frontend source
binding remain the larger owning-task work. No panic guard is added until its
intended contract is established. Primary owns review and acceptance.

The regressions demonstrate:

1. Editing an existing untracked source changes its snapshot.
2. A source change during a nominally successful command makes the receipt

3. A failed fresh browser build prevents all later tests/smoke in that row and
   emits no artifact hashes.
4. A target override is refused before execution or output creation.

Source snapshots identify commits, dirty paths, tracked-diff hashes and
untracked-content hashes. They are provenance checks, not immutable filesystem
snapshots: a change and restoration entirely between samples is not detected,
nor is arbitrary external input captured. Provider rows are explicitly
compile-only; Cargo check does not prove linking, ABI compatibility or execution.

** R7 bounded oracle and mutation coverage

The Sol implementation modifies only =crates/verify/tests/prepared_source.rs=;
the primary inspected the independent interpreter and every mutation family.
The focused command passed *18 tests*:

#+begin_src sh
cd /home/tavis/src/ergodis
nix develop . -c cargo test --locked -j 4 -p ergodis-verify --test prepared_source
#+end_src

The new interpreter reads fixture parts directly, uses ordinary sets and a
fixed-point loop, and enumerates matching body tuples without calling admission's
joins or either production completeness/unification implementation. The source
domain is ={0,1,2}=, with five unary relations and four rules. All 64 pairs of
input subsets are exercised for both three- and four-body join shapes: *128
source instances*. A redundant recursive dependency and a two-body join are
included. The outputs of trace/ranked checkers through prepared bytes and wire
admission, with direct and sorted stores, produce *1,024 closure comparisons*.
A literal expected closure anchors the default fixture independently as well.
After Astra's review, the fourth body atom was strengthened from a duplicate of
the first condition to =f(1)=. Some enumerated masks then change the expected
closure if that fourth condition is omitted, so this tests its semantics as
well as handling four premise slots.

The 12 trace mutations and nine ranked mutations run under both stores;
previous decoder bound, malformed prepared source, binding, and larger binary
fixture mutation tests remain. The new exact-rejection fixtures use prepared
bytes; the new valid closure corpus also covers wire re-admission. Existing
larger binary mutations still use broad rejection assertions. This is a bounded
coverage increment, not exhaustive testing of all programs, predicates,
multi-variable joins or malformed encodings. Production completeness is still
shared; C1214 milestone b is untouched.

** R8 API trust map and existing panic reproductions

The audit separates construction authority from a type's name:

| Surface | Authority / caller obligation | Disposition |
|---------+-------------------------------+-------------|
| =Admitted= and its nested records | Public fields can be hand-built/mutated; relation, tuple, variable and identity invariants are not protected by the type | C1215 opacity/builder design remains open |
| =check_admitted[_bounded]= | Explicitly documented trusted producer-owned in-process fast path | Do not invent a universal malformed-input rejection contract |
| =check=, =check_prepared=, recorded =Source::{Wire,Prepared}= | Re-admit external source material before verification | External rejection tests remain the appropriate gate |
| =datalog_record::Verified= | Private fields and issuer; replay rechecks evidence | Checked capability stronger than the public mutable input structs |
| =Stratified= / =verify_records= | Public mutable result; replay explicitly anticipates nonproducer records but some closure indexes remain unchecked | Two existing panics reproduced; full shape validation still needed |
| Frontend parse/admit/lower source slices | Caller must supply the same bytes across stages; stages do not bind source lifetime/identity | Source-binding/API work remains open |
| Deferred =CompiledObservation= | Same result type as immediate compilation; =verify_compilation= is the verification operation | Do not infer checked authority from the container alone |
| =IndependentCheck= / claim-status ledger | Caller-supplied evidence/status, not construction of proof authority | Requires explicit authority/type design before broader assertions |
