# C988 — Primary-source verification of the four imported results

**Date**: 2026-08-28
**Lane**: `reed-solomon`
**Paper**: `papers/high_weight_grs_cosets`
**Purpose**: verify verbatim, against primary sources, the four external results the
high-weight GRS coset paper imports, with particular attention to whether any of them
carries a characteristic hypothesis that would block dropping `char F_q > r-1` from the
classification clause.

All sources read from the disk-backed literature cache `/tmp/persistent/tavis/lit-search/`.
Each section records the cache key, the sha256 of the bytes read, and whether the bytes are
the published or the arXiv version.

**Notation bridge used throughout.** The paper works with redundancy `r` and full length
`q+1` (support `S`, `|S| = q+1-s`). The sources work with the code dimension `k` of a
length-`n` RS code. For `n = q+1` the dictionary is

```
r  =  n - k  =  q + 1 - k          (paper's redundancy = dual dimension)
d  =  n - k + 1  =  r + 1          (Dür's minimum distance)
rho = q - k = r - 1                (covering radius when the arc is complete)
m   = q + 1 - k = r                (Kaipa 2017's m; ZWK's Nm index)
PG(k_dual - 1, q) = PG(r-1, q)     (ambient of the normal rational curve)
```

Under this dictionary Kaipa's `p ∤ k` and ZWK's `m ≢ 1 (mod p)` are the *same* condition,
and both equal the paper's `p ∤ n` with `n = r-1`.

## 1. Seroussi–Roth 1986

**Cache key** `10.1109/TIT.1986.1057188`;
sha256 `0b5c152819f91d5e410146ada3527b5b795a55fc6170c14a27e43b8c3e39a5f9`;
6 pages. **Version: the published journal article** — IEEE Trans. Inform. Theory
**IT-32** (3), May 1986, pp. 349–354. The running heads and page numbers 349–354 are present
in the bytes, so the pinpoints resolve directly against the version in `refs.bib`. **No
arXiv/journal numbering discrepancy exists** for this source (1986 predates arXiv).

Text was re-extracted column-by-column (the default two-column `pdftotext` output interleaves
the columns and is unusable for quotation); the extraction is lossy on some math glyphs, which
is flagged inline below.

### Verbatim statement (p. 350, left/right column break as printed)

> **Theorem 1:** Let C be a GDRS (n, k, α, ν) code over F = GF(q) such that
> 2 ≤ k ≤ n − ⌊(q − 1)/2⌋; let G be the canonical generator matrix of C; and let g be a
> k-dimensional column vector over F. Then the extension of C generated by the matrix [G|g]
> is MDS if and only if either
> 1) g = u · ν_k(β), where u ∈ F − {0}, β ∈ F ∪ {∞}, and β is not a column generator of C, or
> 2) q is even, k = 3, and g = u · (0,1,0)^T for some u ∈ F − {0}.

(The OCR renders `≤` inconsistently as `I`/`<`; the abstract on p. 349 states the same range
as `2 ≤ k ≤ n − ⌊(q−1)/2⌋`, so the reading above is secure.)

The geometric restatement on the same page:

> **Theorem 1′:** For k ≥ 2, and k ≠ 3 if q is even, an n-arc in PG(k − 1, q) not contained in
> a normal rational curve has at most k − 1 + ⌊(q − 1)/2⌋ points in common with a normal
> rational curve.

The length-`q+1` non-extendability the paper actually wants is stated separately (p. 351):

> **Corollary 1:** Let C = GDRS (q + 1, k, α, ν) over F = GF(q), with 2 ≤ k ≤ ⌊q/2⌋ + 2, and
> k ≠ 3 if q is even. Then, no extension of C is MDS.
>
> *Proof:* Substitute n = q + 1 in Theorem 1 and note that, since all the elements of F ∪ {∞}
> are column generators of the code, condition 1) of the theorem cannot be satisfied, while
> condition 2) does not apply.

> **Corollary 2:** Let C = GDRS (n, k, α, ν) over F = GF(q), with 2 ≤ k ≤ n − ⌊(q − 1)/2⌋, and
> k ≠ 3 if q is even. Then C can be uniquely extended to a maximal MDS code of length q + 1,
> which is GDRS.

And the even-`q` exception in isolation (p. 351):

> **Corollary 3:** Let C = GDRS (2^m + 1, 3, α, ν) over F = GF(2^m). Then the only possible MDS
> extension of C is obtained by appending to G a column of the form (0, u, 0)^T, u ≠ 0.

### Hypotheses

- Field: any finite field `F = GF(q)`, `q` any prime power. **No characteristic hypothesis, no
  parity hypothesis, no lower bound on `q` in Theorem 1 itself.**
- Code: `C` is a GDRS code of length `n ≤ q+1` and dimension `k`, i.e. its columns are points of
  a normal rational curve in `PG(k-1,q)`. Both proper GDRS (`∞` used as a column generator) and
  ordinary GRS are covered; the paper proves the GRS case by reduction to the proper case (p. 354).
- Dimension range: `2 ≤ k ≤ n − ⌊(q−1)/2⌋`. For Corollary 1 (length `q+1`) this reads
  `2 ≤ k ≤ ⌊q/2⌋ + 2`.
- **The only exception is `q` even together with `k = 3`.** It is not excluded from Theorem 1;
  it appears as the extra alternative 2), the nucleus column `(0,1,0)^T` of the conic. Theorem 1′,
  Corollary 1 and Corollary 2 exclude `k = 3, q` even by hypothesis instead.
- Sharpness note (p. 350): the upper bound `n ≥ k − 1 + ⌊(q−1)/2⌋` is necessary for `k = 3`,
  `q ≥ 7`, `q ≢ 1 (mod 4)`. This is a `k = 3` phenomenon only.

### Paper usage

Two places. In `sections/06-high-weight-cosets.tex` (proof of `thm:main`, lines 53–58) the paper
invokes `\cite[Thm.~1]{SeroussiRoth1986}` for the applicability range
`2 ≤ r ≤ |S| − ⌊(q−1)/2⌋`, and concludes that the omitted curve points are exactly the weight-`r`
directions. This is a correct instantiation: `H_S` generates the dual GRS code of dimension `r`
and length `|S|`, so `k ↔ r`, `n ↔ |S|`, and condition 1) says the added column is `u·ν_{r-1}(β)`
for `β ∈ P^1(F_q) \ S = A`. Condition 2) is vacuous because `r ≥ 6 > 3`. The arithmetic bridge
`q ≥ Q*_{r,s} ⟹ q ≥ 2(r+s)−3 ⟹ r ≤ (q+3)/2 − s ≤ |S| − ⌊(q−1)/2⌋` checks out: for `q` odd the
last inequality is an equality, and for `q` even the right-hand side is `q/2 + 2 − s`, strictly
larger than `(q+3)/2 − s`.

In `sections/07-recursive-carriers.tex` (`prop:upper-radius`, lines 574–581) the paper invokes
`\cite[Thm.~1]{SeroussiRoth1986}` for *non-extendability* under `r ≤ ⌊q/2⌋ + 2`, remarking that
"its stated even-field dimension-three exception is irrelevant because `r ≥ 8`."

### Verdict

**MATCHES**, with one pinpoint imprecision worth fixing.

- The range `r ≤ ⌊q/2⌋ + 2` quoted in `prop:upper-radius` is the range of **Corollary 1**, not of
  Theorem 1 (whose range is `2 ≤ k ≤ n − ⌊(q−1)/2⌋`, specializing to Corollary 1's range only
  after substituting `n = q+1`). Likewise, non-extendability of the full length-`q+1` curve is
  Corollary 1's statement. Recommend `\cite[Thm.~1 and Cor.~1]{SeroussiRoth1986}` there.
- The "stated even-field dimension-three exception" is exactly `q` even, `k = 3`, extension by the
  conic nucleus `(0,1,0)^T` (Theorem 1, alternative 2; Corollary 3). Since the paper's global
  hypothesis is `r ≥ 6` (and `r ≥ 8` in the displayed fixed-level cases), the exception is indeed
  irrelevant. **There is no other even-`q` exception anywhere in Seroussi–Roth**, and the main
  theorem's admission of `r ≥ 6` with `q` of either parity is unaffected.
- Section 06's invocation does not mention the `k=3` exception at all. Harmless under `r ≥ 6`, but
  a half-clause parenthetical ("the even-`q` dimension-three alternative does not arise since
  `r ≥ 6`") would make the import self-checking.
- **No characteristic hypothesis in this import.**

## 2. Dür 1994

**Cache key** `10.1016/0012-365X(94)90256-9`;
sha256 `b28e0b84b00255aadf38d6f6b8d2204a76228f5acc0eacb73066cd40401ed9b1`;
7 pages. **Version: the published journal article** — Discrete Mathematics **126** (1994) 99–105
(received 4 Sep 1991, revised 24 Apr 1992). Running heads and page numbers 99–105 present.
**No arXiv/journal numbering discrepancy** for this source.

The `pdftotext` extraction garbles `≤` as `<`/`&`/`Q`, so the two inequality ranges were confirmed
against a rendered page image of the abstract (see quote below, transcribed from the image).

### Verbatim statements

Abstract, p. 99 (transcribed from the page image, glyphs confirmed):

> For doubly-extended Reed–Solomon codes over GF(q) with minimum distance d the covering radius ρ
> is either d−1 or d−2. For 3 ≤ d ≤ q, it is proved that ρ = d−2 if and only if the (q+1)-arc
> consisting of the points of a normal rational curve in PG(d−2, q) is complete. For ρ = d−1 a
> characterization of the deep holes of the sphere packing in Hamming space defined by the code is
> given in terms of their syndromes.

Section 2 opening, p. 100:

> In the sequel let n = q + 1 and 3 ≤ d ≤ q. Then all Cauchy codes over GF(q) of length n and
> minimum distance d are equivalent and have the same covering radius which we denote by ρ(d, q).
> In [5, Proposition 1] it has been proved that ρ(d, q) is either d − 2 or d − 1.

The theorem the paper actually needs, p. 102:

> **Theorem 2.4.** ρ(d, q) = d − 2 if and only if the arc of every normal rational curve in
> PG(d − 2, q) is complete.

Its companion (the deep-hole/syndrome criterion the paper does not use), p. 100:

> **Theorem 2.2.** Let l := q + 2 − d. Then a vector x ∈ K^n has Hamming distance d − 1 from the
> nearest code word if and only if the set
> {κ(1, z, z², …, z^{l−1}, z^{l−1}S(z)) ; z ∈ K} ∪ {κ(0, …, 0, 1, 0), κ(0, …, 0, 0, 1)}
> is a (q + 2)-arc in PG(l, q).

### Hypotheses

- `K = GF(q)`, `q` any prime power. **No characteristic hypothesis, no parity hypothesis.**
- `n = q + 1` (doubly extended / projective RS; Dür's "Cauchy code" with location set `K ∪ {∞}`).
- `3 ≤ d ≤ q`. Under the dictionary `d = r + 1`, this is `2 ≤ r ≤ q − 1`.
- Theorem 2.4 quantifies over *every* normal rational curve in `PG(d−2,q)`; since all normal
  rational curves in a given `PG(m,q)` are projectively equivalent, "every" and "any" coincide,
  which is why Kaipa restates it with "(any)".
- The equivalence is genuinely two-way, so the covering radius is `d − 1` exactly when the
  normal-rational-curve arc extends — i.e. exactly when a one-digit MDS extension of the dual exists.
- Corollary 2.5 (p. 104) then lists the ranges where completeness was known in 1994. The paper does
  not use Corollary 2.5; it supplies completeness from Seroussi–Roth instead, which is the stronger
  route in its parameter window.

### Paper usage

`prop:upper-radius` in `sections/07-recursive-carriers.tex` (lines 579–581): "Dür's
completeness–covering-radius equivalence `\cite{Dur1994}`, in the form recorded by Kaipa
`\cite[Sec.~IV and Prop.~4(1)]{Kaipa2017}`, gives the asserted radius." Also cited without pinpoint
in `thm:recursive-carrier` (line 525) as one half of the "deep-hole identification" gate.

The chain the paper is running is: Seroussi–Roth Corollary 1 gives that the length-`q+1`
normal-rational-curve arc in `PG(r−1,q)` is complete for `2 ≤ r ≤ ⌊q/2⌋+2` (`r ≠ 3` if `q` even);
Dür Theorem 2.4 converts completeness into `ρ = d − 2 = r − 1`. Both directions are within their
stated hypotheses at `r ≥ 6`.

### Verdict

**MATCHES.**

- Theorem 2.4 is the right theorem and the citation is uncontroversial; the paper's `\cite{Dur1994}`
  is un-pinpointed in `thm:recursive-carrier` and pinpointed only indirectly (through Kaipa) in
  `prop:upper-radius`. Adding `\cite[Thm.~2.4]{Dur1994}` costs nothing and makes the import
  checkable without the Kaipa detour.
- The hypothesis `3 ≤ d ≤ q`, i.e. `2 ≤ r ≤ q − 1`, is satisfied throughout the paper's range
  (`r ≥ 6` and `q ≥ Q*_r ≥ 6r − 16`, so `q ≥ r + 1` comfortably).
- **No characteristic hypothesis in this import.**

### Hypotheses

- Proposition 1: `C` is an `[n,k,D]_q` RS code; **if `n = q+1` one must assume `ρ(C) = n − k`**
  (for `n < q+1` this is automatic). No characteristic, parity, or field-size hypothesis. It is a
  pure syndrome/extension dictionary: deep-hole coset classes ↔ one-digit MDS extensions of `C⊥`.
- Proposition 4(1): `m = q + 1 − k = r`, range `2 ≤ m ≤ ⌊q/2⌋ + 2`, **exception `m = 3` when `q` is

  Seroussi–Roth + Dür composite the paper wants, already assembled. No characteristic hypothesis.
- Items 2)–10) of Proposition 4 are not used by the paper. Item 8) is the only one carrying a
  characteristic condition, and it is a *sufficient* condition supplied by Ball's MDS-conjecture
  work, not a restriction on the rest.

### Hypotheses — the direct answer to the crucial question

**Theorems I.4, I.5 and I.6 carry exactly two hypotheses each, and neither is a characteristic
condition:**

1. `2 ≤ k ≤ q − 3`, which under the dictionary is `4 ≤ r ≤ q − 1`.
2. `ρ(PRS(k)) = q − k`, i.e. the covering radius equals `r − 1`. This is a hypothesis, not a
   conclusion, and it is precisely what the Seroussi–Roth/Dür gate supplies.

There is **no `p > k`, no `p > r − 1`, no `q` odd, no `q` even, and no non-divisibility condition**
in the statement or the proof of any of I.4, I.5, I.6. I checked the proofs line by line rather than
relying on the statements:

- *Theorem I.5's proof* computes `syn(u(i,a)) = a·c_{q+1−k}(α_i) − c′_{q+1−k}(α_i)` using the power-sum
  identity `Σ_{α∈F_q^×} α^i = 0` unless `(q−1) | i`, valid in every characteristic, and the side
  condition used is `s − 1 < j ≤ q + 1 − k ≤ q − 1` (i.e. `k ≥ 2`), not a characteristic condition.
  Distinctness of the `q²` classes turns on "the last two components
  `α_i^{q−k−2}(aα_i − (q−k−1))` and `α_i^{q−k−1}(aα_i − (q−k))` cannot both be zero" — these differ by
  `1`, so they cannot both vanish in *any* characteristic. Distinctness from Theorem I.4's classes
  uses only `q + 1 − k ≥ 4`.
- *Theorem I.6's proof* runs entirely through the partial-fraction identity over `F_{q²}` and the
  Vandermonde independence of any `q + 1 − k` columns of `G_{q+1−k}(F_{q²})`. The denominators are
  `µ − µ^q`, nonzero because `µ ∉ F_q`, in every characteristic including 2. Distinctness among the
  `(q+1)q(q−1)/2` classes and from the tangent classes uses only `q + 1 − k ≥ 4`.
- The `p ∤ k` / `p | k` split appears **only** in the description of how the `q² + q` tangent classes
  decompose into `PGL₂(F_q)` orbits (Lemma II.10 and the display quoted above). It changes the orbit
  structure — one orbit of size `q² + q` versus two orbits of sizes `q + 1` and `q² − 1` — but it does
  **not** change whether the words are deep holes, nor how many there are.
- Under the dictionary, ZWK's `p ∤ k` with `k = q + 1 − m` and `q ≡ 0 (mod p)` is `m ≢ 1 (mod p)`,
  i.e. `p ∤ (r − 1)`. This is the *same* condition the paper states in
  `prop:persistent-count-orbits` as "the tangent part is one `PGL₂(q)`-orbit when `p ∤ n`" with
  `n = r − 1`, and the paper's disclaimer "No complete tangent-orbit classification is asserted here
  when `p | n`" is the correct mirror of ZWK's case 2). **The paper's handling of the one genuine
  characteristic-sensitive point in ZWK is already correct.**
- The `q` even/odd conditions in ZWK (Conjecture I.2, Lemma II.10 items 1) and 4), §II-A's treatment
  of `k = q − 2`) all concern `k ∈ {2, q − 2}` or `m = 3`, i.e. redundancy `3` or `q − 1`. They are
  outside the paper's `r ≥ 6` window and outside I.4–I.6's own `2 ≤ k ≤ q − 3` window.
- Theorem I.7 (the total count `q(q+1)²/2`) is proved **only for `k = q − 3`, i.e. `r = 4`.** For
  general `r` it is *not* an ZWK theorem that these are all the deep holes; ZWK say explicitly that
  for `k < q − 3` "even the problem of just determining the number of deep hole classes … is very
  difficult". What I.4–I.6 give for general `r` is a lower bound: `q(q+1)²/2` distinct classes, all
  of weight `r − 1`.

## 5. Consolidated verdict on dropping `char F_q > r − 1`

**With respect to these four imports, dropping `p > r − 1` is safe.** None of the four supplies any
characteristic-dependent input that the paper's classification clause relies on.

Import by import:

1. **Seroussi–Roth Theorem 1 (and Corollary 1)** hold over every `GF(q)` with no restriction on the
   characteristic. Their *only* exception is `q` even together with dimension `k = 3` — the conic
   nucleus in `PG(2,q)`. The paper's global hypothesis `r ≥ 6` clears it by a wide margin, and the
   main theorem's admission of both parities of `q` at `r ≥ 6` is unaffected. There is no second
   even-`q` exception hiding anywhere in that paper.
2. **Dür Theorem 2.4** is a characteristic-free equivalence, valid for `n = q+1` and `3 ≤ d ≤ q`
   (`2 ≤ r ≤ q−1`).
3. **Kaipa Proposition 1** (syndrome ↔ MDS-extension dictionary) and **Proposition 4(1)** (the
   assembled covering-radius statement, range `2 ≤ r ≤ ⌊q/2⌋+2` with the `r = 3`, `q` even exception)
   are likewise characteristic-free in the paper's window. The one characteristic-flavoured item in
   Kaipa's Proposition 4 is part 8) (Ball's `m ≤ 2p − 2` for `q = p^h > p`), which is an *additional
   sufficient range*, not a restriction; the paper does not invoke it.
4. **ZWK Theorems I.4, I.5, I.6** hypothesize only `2 ≤ k ≤ q − 3` and `ρ(PRS(k)) = q − k`. Their
   proofs are characteristic-free, and I verified this at the level of the arguments, not just the
   statements. The only place `p` appears in the surrounding material — ZWK Lemma II.10 and the
   `p ∤ k` / `p | k` orbit split — governs the `PGL₂(F_q)` orbit decomposition of the tangent family,
   not its deep-hole status or its cardinality. Under the paper's dictionary that condition is
   `p ∤ (r − 1)`, and `prop:persistent-count-orbits` already states it correctly and already declines
   to assert a tangent-orbit classification when `p | (r − 1)`.

So the entire content of `p > r − 1` in this paper is internal: it is what makes the maximal Lucas
carrier `M^max_{r,p}` empty (`binom(r−2,j) ≡ binom(r−2,j−1) ≡ 0 mod p` has no solution `j` once
`p ≥ r − 1`). The imported covering-radius gate and the imported rank-two weights survive intact in
every characteristic within `r ≥ 6`, `q ≥ Q*_r`. **If the classification clause can be closed without
the Lucas carrier — by showing that points of `M^max_{r,p}` are not of weight `≥ r−1`, or by
absorbing them into the four strata — then no external citation needs to change and no hypothesis
needs to be re-imported.** The four imports place no obstacle in the way.
