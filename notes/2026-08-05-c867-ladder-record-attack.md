## Result

Three independent attacks on "match or beat the record while keeping the
exceptional symmetry."  All three close, two of them negatively and with

## The ladder is uniform, and the E9 code was the wrong description

The overextended lattice \(E_{10}=II_{9,1}=E_8\oplus U\) reduces mod 2 to a
nondegenerate plus-type space of rank ten with 496 nonsingular classes, giving
\([496,11,240]_2\) with enumerator \(1+1023z^{240}+1023z^{256}+z^{496}\).

Fix a real-root class \(a\).  Its hyperplane and its link split the 496 points
as

\[
 496 = \underbrace{256}_{B(a,v)=0} \;+\; \underbrace{240}_{B(a,v)=1},
\]

and restricting affine functions to the two halves gives \([256,10,120]\) and
\([240,10,112]\).  The link half is the C865 affine level code, enumerator for
enumerator.  Folding the link by \(v\mapsto v+a\) — the same antipodal fold
that took E8 to E7 in C682 — returns \([120,9,56]\) exactly.

So the affine level is not a special construction needing the affine root
lattice at all.  It is the root link of a single \(E_{10}\) root, and the
root-link-and-fold step is one uniform operation applied at every level:

\[
 [496,11,240]_{E_{10}}
 \to [240,10,112]
 \to [120,9,56]_{E_8}
 \to [28,7,12]_{E_7}
 \to [27,6,12]_{E_6}.
\]

This supersedes the Plotkin description in C865.  That identity is still true,
but it described the code by an accident of the degenerate carrier rather than
by the operation that produces it.

## Attack one — a tenth dimension at E8 with full symmetry: impossible

An exact \([120,10,56]\) code exists, so the record at that length is
dimension-maximal one step above ours.  Ours is not.  The question is whether
the missing generator can be added \(O_8^+(2)\)-equivariantly.

Invariant codes of dimension ten containing \(C_{E_8}\) correspond to nonzero
fixed vectors of \(\mathbf F_2^{120}/C_{E_8}\) under the group generated by all
120 reflections in nonsingular vectors.  Computing that fixed space gives
dimension nine — that is, only \(C_{E_8}\) itself.

**There is no \(O_8^+(2)\)-invariant binary code of dimension ten containing
the E8 root-pair code.**  The record dimension and the full root-pair symmetry
are incompatible.  This settles the C682 open item "the tenth classical
dimension" in the negative, in the containment case, and it converts a guess
("it may necessarily break the symmetry") into a computed obstruction.

The same computation at the affine level, with the group enlarged by the level
translation, returns dimension ten — again exactly the code itself.  No
invariant enlargement exists there either.

## Attack two — beating 112 at length 240 by rebalancing: impossible

C865 exhibited the level code as a Plotkin \(|u\,|\,u+v|\) sum of
\([120,9,56]\) with the repetition code, badly unbalanced.  The obvious repair
is to rebalance the two components.  It cannot work.

For any such code of length 240 and dimension ten with length-120 halves,
\(d=\min(2d_1,d_2)\) with \(k_1+k_2=10\).  The binary Plotkin bound gives
\(d_2\le 120\cdot 2^{k_2-1}/(2^{k_2}-1)\), so \(k_2\ge2\) already caps \(d\) at
80, and \(k_2=1\) caps it at \(2\cdot 56=112\) because 56 is the exact
\([120,9]\) optimum.  The maximum over all splits is 112, attained only by the
split we already have.

**112 is optimal among all Plotkin doublings at these parameters.**  The gap to
the record range 114–116 is not a rebalancing failure; reaching it requires
abandoning the doubling structure, which at this carrier means abandoning the
root link.

## Attack three — the E10 root hyperplane: closer, still short

The 256-point half is the more interesting one, because unlike the link it is
not a doubling.  It is a rank-nine parabolic quadratic space, equivalently
\((E_8\oplus A_1)/2\), and its code is

\[
 [256,10,120]_2,
 \qquad
 W(z)=1+256z^{120}+510z^{128}+256z^{136}+z^{256},
\]

a genuine three-weight code with the full stabilizer symmetry.  The record at
\([256,10]\) is \(d=124\), exact.  We are four short.

That is the closest any level above E8 gets, and it is the best remaining
target: the shortfall is four rather than the 2–4 at length 240, but the
carrier is nondegenerate, so no structural no-go of the kind proved above
applies to it.

## Where the quantum distance has to come from, and it is free

Every unsigned lift on this ladder stalls at CSS distance four, one below the
exact \([[28,14,5]]\) and \([[120,102,5]]\) records.  C682 searched entrywise
phase decorations at E7 and failed, and correctly identified that the phases
should come from the root data rather than from generator entries.  That data
exists canonically and did not have to be searched for.

\(E_8\) is a module of rank four over the Eisenstein integers \(\mathbf Z[\omega]\),
and 2 is inert there, so

\[
 E_8/2E_8 \;\cong\; \mathbf F_4^4,
 \qquad
 Q(v)=\textstyle\sum_i v_i^3 = \#\{i: v_i\neq0\} \bmod 2,
\]

with polarization \(B(v,w)=\operatorname{Tr} h(v,w)\) for the Hermitian form
\(h(v,w)=\sum_i v_i \bar w_i\).  The identity
\(Q(v+w)=Q(v)+Q(w)+\operatorname{Tr}h(v,w)\) is verified over the whole space.
The 120 nonsingular vectors are exactly those of odd \(\mathbf F_4\)-weight —
12 of weight one and 108 of weight three — and multiplication by \(\omega\)
acts freely on them in 40 orbits of size three.

So the quadratic form that carries the entire ladder is already
\(\mathbf F_4\)-intrinsic, and \(\omega\) is a canonical order-three symmetry
of the 120 coordinates.  That is precisely the alphabet the Hermitian
construction wants, delivered by the lattice rather than by a search.  What
remains is to find which \(\mathbf F_4\)-linear code on this carrier is
Hermitian self-orthogonal with dual distance five; the plain extension of
scalars from our binary code is not it, since its dual tetrads survive
verbatim.

## EJ + TT closeout and mystery ledger

- **Settled — the affine level is a root link.**  The E9 code of C865 is the
  \(E_{10}\) root-link code; the ladder is one uniform operation throughout,
  and the Plotkin description was carrier-accidental.
- **Settled — no symmetric tenth dimension at E8.**  Computed obstruction, not
  a failed search.  Closes the C682 open item in the containment case.
- **Settled — no Plotkin rebalancing at length 240.**  112 is the maximum over
  all splits.
- **Settled — the \(\mathbf F_4\) alphabet is canonical and free.**  The
  Eisenstein structure supplies it; C682's phase search was looking in the
  wrong place.
- **Open — the four-unit gap at \([256,10]\).**  The nondegenerate carrier is
  the only level above E8 with no proved obstruction, and it is the natural
  target.
- **Open — whether a dimension-ten \([120,10,56]\) code exists that is
  invariant under a large but proper subgroup of \(O_8^+(2)\).**  Only the
  containment case is closed.
- **Open — the Hermitian code on the Eisenstein carrier.**  Which
  \(\mathbf F_4\)-linear code has dual distance five is untested.
- **Open — \([496,11]\) has no public bound**, so the E10 level cannot be
  scored at all.
