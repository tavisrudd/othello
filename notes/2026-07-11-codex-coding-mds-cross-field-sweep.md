## 1. Strongest surviving theorem: a zero-sum recovery hypergraph

Let (p) be an odd prime, (q=p^h) with (h\ge 2),

\[
c(t)=(1,t,\ldots,t^p)^T\quad(t\in\mathbb F_q),\qquad x=e_{p-1},
\]

and let (C_{p,h}) be the row-space code generated by

\[
G=[\,c(t):t\in\mathbb F_q\mid x\,].
\]

### 1.1 Code and circuit theorem

**[PROVED]** (C_{p,h}) is an optimal

\[
[q+1,p+1,q-p]_q
\]

NMDS code with exact all-symbol linear locality (p).  Its minimum dual
supports are exactly

\[
\{x,c(t_1),\ldots,c(t_p)\},\qquad
t_i\text{ distinct},\quad \sum_i t_i=0.
\]

Proof ledger:

1. Any (p+1) finite columns are Vandermonde-independent, so (G) has rank
   (p+1).
2. A codeword is
   \[
   (f(t))_{t\in\mathbb F_q}\mathbin\Vert a_{p-1},
   \qquad f(T)=\sum_{i=0}^p a_iT^i.
   \]
   A nonzero (f) has at most (p) finite roots.  Equality in the distance
   bound is attained by the polynomial of an affine 𝔽_p-line
   (a+b\mathbb F_p):
   \[
   \prod_{u\in\mathbb F_p}(T-a-bu)
   =(T-a)^p-b^{p-1}(T-a),
   \]
   whose (T^{p-1})-coefficient vanishes.  Hence (d=q-p).
3. Every set of at most (p) columns is independent.  A set containing (x)
   and at most (p-1) finite columns is independent by the Vandermonde moment
   equations in degrees (0,\ldots,r-1).  Thus (d(C^\perp)=p+1), and both
   code and dual have Singleton defect one.
4. Expanding the generalized Vandermonde determinant shows
   (x\in\langle c(t_1),\ldots,c(t_p)\rangle) exactly when
   \(\sum_i t_i=0\).  Affine 𝔽_p-lines supply such a circuit through every
   coordinate, proving exact all-symbol locality (p).
5. The Singleton-like LRC bound gives
   \[
   d\le n-k-\lceil k/p\rceil+2=q-p,
   \]
   so the code is LRC-optimal.

**[REFUTED, boundary case]** At (h=1), Frobenius makes the finite first- and
(p)-th-power rows dependent; the stated rank-(p+1) NMDS theorem therefore
starts at (h=2).  For (p=q=3) the resulting code is instead the MDS
([4,3,2]_3) code.

### 1.2 Exact availability versus adversarial local-repair tolerance

For the distinguished coordinate (x), let

\[
\mathcal H_x=
\left\{S\in{\mathbb F_q\choose p}:\sum_{s\in S}s=0\right\}.
\]

This is the complete hypergraph of minimum-size helper sets for (x).  Let
(Z_p(\mathbb F_q)) be the largest subset of 𝔽_q containing no (p)
distinct elements summing to zero.

**[PROVED]**

\[
\nu(\mathcal H_x)=q/p,
\qquad
\tau(\mathcal H_x)=q-Z_p(\mathbb F_q).
\]

The matching equality follows from a parallel class of affine
𝔽_p-lines and the cardinality upper bound.  A helper-failure set hits every
local repair precisely when its complement contains no zero-sum (p)-set,
which proves the transversal equality.  Thus (x) remains locally repairable
after every set of at most

\[
q-Z_p(\mathbb F_q)-1
\]

helper failures.

**[LITERATURE-IMPORTED]** For fixed (p\ge5), Sauermann proves

\[
Z_p(\mathbb F_p^h)\le C_p(2\sqrt p)^h=o(p^h).
\]

For (p=3), the Ellenberg–Gijswijt cap-set bound gives
(Z_3(\mathbb F_3^h)=o(3^h)).  Therefore

\[
\frac{\tau(\mathcal H_x)}{\nu(\mathcal H_x)}
=p\left(1-\frac{Z_p(\mathbb F_q)}q\right)\longrightarrow p.
\]

Every (p)-uniform hypergraph satisfies τ≤pν, since the union of a
maximum matching is a transversal.  These recovery hypergraphs therefore
asymptotically attain the universal largest possible cover/matching ratio.

**[PROVED, important asymmetry]** Every minimum repair set of an evaluation
coordinate (c(t)) contains (x).  Its disjoint minimum-repair availability is
therefore exactly one.  Only the distinguished coordinate has the extremal
availability/tolerance behavior.

### 1.2.1 The complete radius-(p+1) profile

The minimum-support profile is not the whole service-rate story.  If repair
sets of size at most (p+1=k) are admitted, every (p+1) finite NRC columns
form a basis.

**[PROVED]** For every finite evaluation coordinate (c(t)),

\[
\nu_t^{\le p+1}=\left\lfloor\frac{q+1}{p+1}\right\rfloor,
\qquad
(\nu_t^{\le p+1})^*=\frac{q+1}{p+1}.
\]

For the integral lower bound, choose one locality-(p) repair through (t),
which consumes (x) and (p-1) finite helpers, then split as many as possible
of the remaining (q-p) finite helpers into ((p+1))-sets.  Each such set is a
basis.  For the upper bound, at most one disjoint (p)-set can occur because
all contain (x); every other repair uses at least (p+1) helpers.

For the fractional value, let (L) be the total weight on (p)-helper repairs
and (O) the total weight on larger repairs.  The (q) helper capacities give

\[
L\le1,\qquad pL+(p+1)O\le q,
\]

and hence (L+O\le(q+1)/(p+1)).  Equality is attained by putting total weight
one uniformly on the affine lines through (t), then spreading the remaining
finite-helper capacity uniformly over all-finite ((p+1))-subsets.

Since (q=p^h\equiv(-1)^h\pmod{p+1}), the additive fractional/integral gap is
zero for odd (h) and exactly (2/(p+1)) for even (h).

**[PROVED]** If the chosen coordinate is systematic and servers have unit
capacity, its axial service-rate intercept (direct read plus fractional repair)
is

\[
1+q/p\quad\text{for }x,
\qquad
1+(q+1)/(p+1)\quad\text{for finite }t.
\]

The second formula would be missed by looking only at minimum circuits.
This service-rate statement uses fractional matchings of the full recovery
hypergraph; it does not imply a batch-code theorem for simultaneous requests
to different symbols.  Nor does it canonically determine stopping sets, which
depend on a selected parity-check matrix.

### 1.3 What is and is not new

**[CLOSED as headline novelty]** The bare code construction is a one-column
puncture of the classical Roth–Lempel matrix, and NMDS-to-optimal-LRC conversion
is established machinery.  Han–Fan Lemma 6 already contains, algebraically, the
zero-sum minimum-circuit classification used here.  The parameters, NMDS
status, circuits, and Singleton-bound equality must not be sold as novelty.

**[OPEN novelty candidate]** The potentially new package is:

> the exact unequal availability profile and an explicit optimal NMDS-LRC whose hot-symbol recovery
> hypergraph has a perfect matching but an asymptotically maximum possible
> transversal/matching gap.

The local-repair-tolerance invariant itself is not new: Pamies-Juarez,
Hollmann, and Oggier define it as the minimum hitting set of all bounded-size
repair supports.  The candidate contribution is the exact additive-combinatorial
evaluation, the complete bounded-radius availability/service profile, and its
extremal separation from conventional disjoint availability.

### 1.4 Positive-rate, positive-distance lift

The load-bearing step is a general seed-and-lift principle, not a special
feature of the (q=9) matrix.

**[PROVED: bounded-repair preservation under concatenation]** Let
(I\le\mathbb F_q^{n_0}) be an inner ([n_0,k_0,d_0]_q) code and let
(O\le\mathbb F_{q^{k_0}}^N) be an outer code.  Form the ordinary
concatenation (C=O\circ I) through an 𝔽_q-linear identification of one
outer symbol with (I).  Fix (s<d(O^\perp)).  Every word
(w\in C^\perp) of (q)-ary weight at most (s) is blockwise inner-dual:

\[
w=(w_1,\ldots,w_N),\qquad w_j\in I^\perp\text{ for all }j.
\]

Indeed, each block functional has a unique trace representation
(a\mapsto\operatorname{Tr}(\beta_j a)).  Orthogonality to the concatenated
code makes β an outer-dual word, while
(\operatorname{wt}(\beta)\le\operatorname{wt}_q(w)\le s<d(O^\perp)).
Thus β=0 and every block annihilates (I).

If additionally (s<2d(I^\perp)), such a nonzero (w) occupies only one
block.  In particular, when (d(I^\perp)=r+1) and
(d(O^\perp)\ge r+2), the complete repair hypergraph using at most (r)
helpers is copied block-for-block with no new cross-block repair supports.

**[PROVED: seed-and-lift corollary]** Any fixed inner seed with positive distance,
dual distance (r+1), all-symbol locality (r), and a specified distribution
of bounded-repair invariants can be combined with outer codes having positive
rate, distance, and dual distance to produce a fixed-alphabet asymptotically
good LRC family with exactly the same invariant distribution.  Thus a finite
seed with τ>ν on a positive fraction of coordinates suffices to produce an
asymptotically good family with the same positive fraction.  Standard
concatenated-LRC results preserve declared locality; the extra content here is
preservation of the *complete* bounded-size recovery hypergraph.

Let (C_0=C_{3,2}), the inner code over 𝔽_9.  It has parameters
([10,4,6]_9), all-symbol locality (3), one distinguished coordinate with

\[
(\nu,\tau)=(3,5),
\]

and nine ordinary coordinates with ((\nu,\tau)=(1,1)).

**[PROVED]** Put (Q=9^4=6561), fix an 𝔽_9-linear isomorphism
(phi:\mathbb F_Q\to C_0), and let

\[
O_N=[N,K_N,D_N]_Q
\]

be an 𝔽_Q-linear outer code with (d(O_N^\perp)\ge5).  The ordinary
concatenation

\[
C_N=\{(\phi(a_1),\ldots,\phi(a_N)):(a_1,\ldots,a_N)\in O_N\}
\]

has

\[
n=10N,\qquad k=4K_N,\qquad d\ge6D_N.
\]

More strongly, every dual word of (C_N) of weight at most four is supported
inside one inner block and is a word of (C_0^\perp).  Therefore the complete
locality-three repair hypergraph, not merely a declared subfamily of repairs,
is block-local.  It follows that:

- every coordinate has exact locality (3);
- exactly (1/10) of the coordinates have ((\nu,\tau)=(3,5));
- the remaining (9/10) have ((\nu,\tau)=(1,1)).

Proof of the block-local claim: a dual block vector induces an 𝔽_9-linear
functional on the outer symbol space. Coordinate-free, the vector of these
functionals annihilates the outer code by the definition of concatenation, so it belongs to the
functional outer dual. Choosing a trace pairing identifies that dual alphabet with 𝔽_Q and
recovers the familiar coefficients (a_i\mapsto
\operatorname{Tr}(\beta_i a_i)). Coordinate weight at most four implies that β has
outer support at most four, contradicting (d(O_N^\perp)\ge5), unless
(eta=0).  Each block then annihilates the entire inner code and hence lies
in (C_0^\perp), whose minimum weight is four.  Only one nonzero block can
remain.

**[LITERATURE-IMPORTED / PROVED CONSEQUENCE]** Random linear outer codes over

This closes the two largest defects of the one-block construction. Basic LRC

## 3. MDS shortening and completion distance

Let (H) be an (r\times n) MDS parity-check matrix, (x) an external column,
and

\[
\mathcal B_x=\{B\in{[n]\choose r-1}:x\in\langle H_B\rangle\}.
\]

**[PROVED]** The completion-distance insertion invariant is

\[
\delta_x=\tau(\mathcal B_x).
\]

It is the minimum number of coordinates that must be shortened away so that
(x) reaches distance (r) from the shortened code, equivalently so that (x)
becomes an MDS lengthening column.  In storage language, τ−1 is the exact
number of arbitrary helper failures under which some locality-((r-1)) repair
remains.  This should be called the **MDS-lengthening deletion number** or
**redundancy-bound deep-hole promotion number**, not simply a deep-hole number:
an MDS code may have covering radius (r-1), so a word can already be a deep
hole before reaching distance (r).

**[PROVED, prime NRC special case]** For (2\le d\le p-1), the NRC point
(x=e_{d-1}) satisfies

\[
\delta_x=p-\left\lfloor\frac{p+d^2-2}{d}\right\rfloor.
\]

This combines the Dias da Silva–Hamidoune restricted-sumset theorem with a
matching arithmetic-progression construction.  It gives an exact adversarial
shortening radius, though the additive-combinatorial input is classical.

## 4. Closed Cheng–Murray route

external (x), write 𝒩(x) for all ((r-1))-representations and
𝒩_y(x) for those using (y).  Then

\[
(C\setminus\{y\})\cup\{x\}\text{ is an arc}

## 5. Frobenius-marked MDS extension arrangements

For an 𝔽_s-rational extension column of a Frobenius-stable conic arc over
𝔽_{s^2}, the forbidden spans form an 𝔽_s-subspace arrangement.  Its
intersection lattice gives the exact number of rational legal extensions:

\[
N_F(A)=\frac1{s-1}\sum_X\mu(V,X)s^{\dim_F X}.
\]

**[PROVED, three conjugate pairs]** Let (m_1,m_2,m_3) be the three mate
𝔽_s-lines.  Put ε=0 if they concur and ε=1 if they form a triangle.  Of
the six other conjugate-secant intersection points, let (h) lie outside
(m_1\cup m_2\cup m_3).  Then

\[
\chi(t)=(t-1)(t^2-2t+\epsilon-h),\qquad
N_{\rm legal}=s^2-2s+\epsilon-h.
