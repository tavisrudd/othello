## 4. Candidates evaluated and DECLINED (with reasons)

### 4.1 `G(C_{2m})` even-cycle slice — trivial

Lemma 14.2: `G(C_{2m}) = 0` for every `m ≥ 2` (the paper's literally-named byproduct alongside
`G(P_m)`). This is the all-zeros constant sequence; OEIS does not accept a trivial constant.
**Decline.** It is subsumed by the full `G(C_n)` entry (§1), where it is the even-index sublattice.

### 4.2 `D_{4n}` (three-point) transitive template nimbers — constant / pure parity

From §5–§8 and the §8 template table, each transitive template value is constant or a bare parity:
- Möbius ladder `G(M_{4n}) = 1` for all `n ≥ 2` (Thm 5.2) — constant.
- prism `G(C_{2n} □ K_2) = 0` for all `n` (Thm 5.3) — constant.
- rotation template `∅`, value `0` — constant.
- ladder `G(L_k) = k mod 2` (eq. 7.5) — this is **A000035** (period-2 parity), already trivially in
  OEIS; the reflection templates `L_{n-1}, L_n, L_{n-2}` just re-index it.

None is an extendable nontrivial integer sequence. The `t_K` "template table" itself (§8) is a
finite lookup keyed by `(stabilizer, d-parity, e-parity)`, not a sequence. **Decline all.**

### 4.3 S₄ / A₅ regular Cayley Node-Kayles nimbers — finite lookup table

From `notes/2026-07-17-c260-a5-template-nimber-crosscheck.json` (Appendix A): 9 values, keyed by
group and sorted pairwise-product-order signature —
S₄ `(2,3,3)=0, (2,3,4)=0, (3,3,3)=0, (3,4,4)=0`; A₅ `(2,3,5)=1, (2,5,5)=1, (3,3,5)=0, (3,5,5)=0,
(5,5,5)=0`. This is a finite 9-cell table indexed by a signature, not a 1-D sequence with an
offset, and it is not extendable (S₄ and A₅ each have finitely many involution-triple classes).
OEIS wants infinite/extendable sequences. **Decline as a standalone sequence.** Best home: a data
table / `%C` on a broader "Node-Kayles on cubic Cayley graphs of small groups" entry, if one is ever
created — out of scope here.

### 4.4 Value histogram and `m` histogram — `q`-specific enumeration artifacts

`value_histogram {0:172668, 1:36456, 2:13296, 3:18924}` and `m_histogram {...}` (C263 JSON) count
tame legal pairs over the fixed field set `q ∈ {5,7,11,13,17,19,23}`. They depend on the chosen
finite sample of fields, are not a function of a single running index, and change if the field set
changes. Not OEIS sequences. **Decline.**

### 4.5 P/N-position classification over `q` — characteristic functions of arithmetic progressions

Corollaries 9.1 and 14.5 give, for fixed `(n or m, torus)`, a P/N verdict that is a characteristic
function of residue classes of `q` mod `8n` (or `2m`) — e.g. even-`d`: P iff `4n | q ∓ 1`. These
are indicator sequences of arithmetic progressions, which OEIS generally discourages, and they are
`q`-indexed (indexed by prime field), not by a clean running integer. **Decline.**

Node-Kayles on the cycle `C_n` — and it is worth a priority stamp, though it is admittedly a 0/1

deliverable is, plainly, "one submit, one crossref, five declines," backed by live OEIS collision
